# Работа 2. Кейс 2 — Описание содержания проекта

## Задание

По шаблону «Описание содержания проекта» ([case-2-template.docx](case-2-template.docx)),
вводному материалу ([case-2-task.docx](case-2-task.docx)) и результатам Кейса 1
(Устав — [`../lab-1/05-charter.docx`](../lab-1/05-charter.docx)) сформировать Описание
содержания по своему проекту. Документ разрабатывает руководитель проекта вместе с командой.

Описание содержания отвечает на вопрос «какие работы входят в проект, а какие нет»: в нём
цель из Устава, измеримые критерии её достижения и требования к продукту, задачи с результатами
(из них потом строится ИСР), границы проекта, критерии приёмки, ограничения и допущения
с последствиями их невыполнения.

## Как открыть

Документы — обычные `.docx`, открываются в Word или LibreOffice. Файлы сжаты без потерь
скриптом [`../../life-safety/compress-docx.sh`](../../life-safety/compress-docx.sh)
(`oxipng` и `zip` из `flake.nix`):

```bash
cd ~/repos/uni && direnv allow                     # один раз
./life-safety/compress-docx.sh исходник.docx project-management/lab-2/01-scope-statement.docx
```

`.doc` переводится в `.docx` через LibreOffice: `nix shell nixpkgs#libreoffice -c soffice --headless --convert-to docx файл.doc`.
