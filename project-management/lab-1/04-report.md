## 2. Название проекта

**«АкваДом — вода в один клик» — разработка мобильного приложения для заказа воды
с программой лояльности.**

Сформировали: РП (полная формулировка) и ЧК (краткое название). Согласовано З и С.

## 3. Цель проекта (SMART)

> До 25.12.2026 разработать и опубликовать в App Store и Google Play мобильное приложение
> для клиентов ООО «АкваДом», в котором можно заказать воду, выбрать интервал доставки,
> оплатить заказ онлайн, начислить и списать баллы программы лояльности и получать
> push-уведомления о статусе заказа, чтобы к 31.03.2027 число заказов, принимаемых
> операторами по телефону, сократилось на 40 %.

| Критерий | Как выполнен |
| --- | --- |
| **S** — конкретная | Приложение для iOS и Android с пятью функциями из описания продукта |
| **M** — измеримая | Публикация в двух магазинах; приёмка пяти функций по тестам; число телефонных заказов в марте 2027 г. на 40 % меньше среднемесячного за сентябрь–ноябрь 2026 г. |
| **A** — достижимая | Одна кодовая база для двух платформ; программа лояльности уже существует, её нужно только подключить |
| **R** — актуальная | 70 % заказов идёт по телефону, операторы перегружены и ошибаются; аналоги не поддерживают лояльность ООО «АкваДом» |
| **T** — ограничена во времени | Запуск до 25.12.2026, эффект оценивается на 31.03.2027 |

Сформировал РП совместно с ЧК. Согласовано З и С.

## 4. Описание продукта проекта

Мобильное приложение для iOS и Android, позволяющее клиентам ООО «АкваДом» заказывать воду,
выбирать время доставки и оплачивать заказ онлайн. Отличие от аналогов — интеграция
с программой лояльности ООО «АкваДом» и уведомления о статусе заказа.

**Обоснование.** Сейчас 70 % заказов принимается по телефону: это увеличивает нагрузку
на операторов и приводит к ошибкам при оформлении. Аналогичные приложения существуют,
но не поддерживают программу лояльности ООО «АкваДом». Приложение снизит нагрузку
на операторов на 40 % и увеличит число повторных заказов.

Сформировал З. Согласовано С и РП.

## 8. Концепция выполнения проекта

Сформировал ЧК Снегирёв А. П. РП согласовал её с З и С.

Приложение делается на кросс-платформенном фреймворке: одна кодовая база для iOS и Android.
Оплата подключается через платёжного провайдера, данные карт в приложении не хранятся.
