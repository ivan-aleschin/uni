# Работа 1. Инициация проекта

## Задание

1. Собрать команду из 3–4 человек.
2. Распределить роли: Заказчик (З), Спонсор (С), Руководитель проекта (РП), Член команды (ЧК).
3. Придумать названия трёх фирм.
4. Заказчик составляет предварительное описание продукта.
5. Спонсор составляет бюджет.
6. Заказчик, Спонсор и ЧК формируют ограничения.
7. РП вместе с ЧК формулирует цель по SMART и название проекта.
8. Согласовать всё внутри группы (З, С, РП, ЧК).
9. Показать преподавателю описание продукта, бюджет, ограничения, цель и название,
   допущения и концепцию.
10. После одобрения заполнить Устав проекта по шаблону и подготовить отчёт РП.

## Итог этапа

- **Название проекта:** «АкваДом — вода в один клик» — разработка мобильного приложения для заказа воды
  с программой лояльности.
- **Цель (SMART):** до 25.12.2026 разработать и опубликовать в App Store и Google Play
  мобильное приложение ООО «АкваДом» с заказом воды, выбором интервала доставки, онлайн-оплатой,
  программой лояльности и уведомлениями о статусе заказа, чтобы к 31.03.2027 сократить число заказов, принимаемых по телефону, на 40 %.
- **Ограничения от Заказчика:** бюджет не более 1 200 000 руб.; запуск не позднее 25.12.2026.
- **Ограничения от Спонсора:** резерв 60 000 руб. только по решению Спонсора; внешние подрядчики
  только с его согласия.
- **Ограничения от ЧК:** версии ОС (iOS 15.0+, Android 8.0+); подключение к лояльности только
  через существующие интерфейсы.
- **Ограничение от РП:** заморозка функциональности 04.12.2026 и отправка на модерацию
  не позднее 14.12.2026.
- **Допущения:** проверка в магазинах не дольше 7 дней, интерфейсы Заказчика не меняются (ЧК);
  рост ставок разработчиков не более 5 % (РП).

Бюджет (1 200 000 руб.) по замечанию преподавателя в формулировку цели не входит —
это ограничение, а не цель.

## Как собрать PDF

Исходники документов — `0*.md`, PDF собираются из них через pandoc с движком typst
(оба подключены в `flake.nix`, оформление — [`../pdf.yaml`](../pdf.yaml)):

```bash
cd ~/repos/uni && direnv allow        # один раз
cd project-management/lab-1
make                                  # пересобрать изменённые PDF
```

Без direnv: `nix develop -c make`.
