# Цель, название и ограничения проекта

**Подготовил:** Руководитель проекта Алёшин Иван Кириллович, ООО «Разработчик»\
**При участии:** Член команды Снегирёв А. П.\
**Дата:** 07.10.2026

## 1. Название проекта

«АкваДом — вода в один клик» — разработка мобильного приложения для заказа воды с программой лояльности.

Краткое название: «АкваДом — вода в один клик» (предложил Снегирёв А. П.).

## 2. Цель проекта по SMART

До 25.12.2026 разработать и опубликовать в App Store и Google Play мобильное приложение
для клиентов ООО «АкваДом», в котором можно заказать воду, выбрать интервал доставки,
оплатить заказ онлайн, начислить и списать баллы программы лояльности и получать
push-уведомления о статусе заказа, чтобы к 31.03.2027 число заказов, принимаемых
операторами по телефону, сократилось на 40 %.

| Критерий | Как выполнен |
| --- | --- |
| S (конкретная) | Мобильное приложение для iOS и Android с пятью функциями: заказ воды, выбор интервала доставки, онлайн-оплата, программа лояльности, уведомления о статусе заказа |
| M (измеримая) | Приложение опубликовано в двух магазинах, функции приняты Заказчиком по приёмочным тестам; телефонных заказов в марте 2027 г. на 40 % меньше, чем в среднем за сентябрь–ноябрь 2026 г. |
| A (достижимая) | Одна кодовая база на кросс-платформенном фреймворке; программа лояльности у Заказчика уже есть, её нужно только подключить |
| R (актуальная) | 70 % заказов принимается по телефону, операторы перегружены и ошибаются; аналоги не поддерживают программу лояльности ООО «АкваДом» |
| T (ограничена во времени) | Запуск до 25.12.2026, результат по телефонным заказам оценивается на 31.03.2027 |

## 5. Концепция проекта

Сформировал Снегирёв А. П.

Приложение пишется на кросс-платформенном фреймворке, одна кодовая база для iOS и Android.
Оплата идёт через платёжного провайдера, данные карт в приложении не хранятся. Статус заказа
приложение получает из учётной системы ООО «АкваДом» и присылает клиенту push-уведомление.
