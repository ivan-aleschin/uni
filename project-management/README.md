# Основы управления проектами

Практика ведётся одним сквозным учебным проектом в команде из четырёх человек. У каждого
участника своя роль (Заказчик, Спонсор, Руководитель проекта, Член команды) и своя фирма;
документы проекта готовятся по ролям, согласуются внутри группы и показываются преподавателю.

Моя роль — **Руководитель проекта** (Алёшин Иван Кириллович, ООО «Разработчик»).
