# ЛР2. Теория: конечные автоматы

Подробнее, чем в [SUMMARY.md](SUMMARY.md). Отчёт с результатами — [README.md](README.md).

## 1. Определение

Конечный автомат — пятёрка `A = (Q, T, t, q0, F)`:

- `Q` — конечное множество состояний;
- `T` — входной алфавит (конечный, непустой);
- `t` — функция переходов;
- `q0 ∈ Q` — начальное состояние;
- `F ⊆ Q` — множество заключительных (конечных, допускающих) состояний.

Автомат читает строку слева направо по одному символу, на каждом такте меняя состояние по `t`.
Строка **допускается**, если после чтения последнего символа автомат оказался в состоянии из `F`.
Язык автомата `T(A) = { x ∈ T* | t(q0, x) ∈ F }`.

Функция переходов расширяется со символов на строки рекурсивно:
`t(q, ε) = q`, `t(q, ya) = t(t(q, y), a)` — сначала прочитали `y`, потом ещё один символ.

В нашем формате `q<N>` — состояние из `Q \ F`, `f<N>` — состояние из `F`, `q0` — начальное.

## 2. ДКА и НКА

| | ДКА (детерминированный) | НКА (недетерминированный) |
| --- | --- | --- |
| `t(q, a)` | одно состояние или «нет перехода» | множество состояний `⊆ Q` |
| Признак в графе | из вершины по каждому символу не больше одной стрелки | есть вершина с двумя стрелками с одинаковой меткой |
| Разбор строки | один проход, один путь | надо перебрать все пути (или держать множество текущих состояний) |
| Допуск | путь закончился в `F` | **хотя бы один** путь закончился в `F` |

Пример из методички: в грамматике с предложениями `a, a0, a00, …, b0, b00, …` из `S` по `a`
идут две стрелки — в `f` и в `D`, то есть `t(S, a) = {f, D}`, и автомат недетерминирован.

Иногда ДКА требуют **полным**: переход есть из каждого состояния по каждому символу. Неполный
ДКА дополняют «мёртвым» состоянием, в которое ведут все отсутствующие переходы и из которого
выхода нет. Для распознавания это ничего не меняет, поэтому программа его не добавляет:
«перехода нет» — это и есть отказ.

## 3. Теорема о детерминизации

Для любого НКА `A` существует ДКА `A'` с тем же языком: `T(A) = T(A')` (Рабин и Скотт, 1959).
Следствие: НКА не мощнее ДКА, просто компактнее. Платить за детерминизм приходится числом
состояний: у ДКА их может оказаться до `2^|Q|` (каждое — подмножество `Q`).

### Построение подмножеств (subset construction)

Идея методички: если `t(q, a) = {p1, …, pk}`, объявляем это множество новым состоянием `q'`
и определяем `t(q', a) = ∪ t(p, a)` по всем `p ∈ q'`. Повторяем, пока появляются новые множества.

Алгоритм (так и сделано в `determinize()`):

```
D0 := {q0};  очередь := [D0];  состояния ДКА := {D0}
пока очередь не пуста:
    D := взять из очереди
    для каждого символа a:
        E := ∪ t(p, a) по p ∈ D
        если E пусто — перехода по a нет, к следующему символу
        если E новое — добавить в состояния ДКА и в очередь
        t'(D, a) := E
F' := { D | D ∩ F ≠ ∅ }
```

Почему это правильно: после чтения строки `x` состояние ДКА равно множеству **всех** состояний,
в которых НКА мог оказаться после `x` (доказывается индукцией по длине `x`). НКА допускает `x`,
если среди этих состояний есть конечное, — ровно определение `F'`.

Обход начинается с `{q0}`, поэтому недостижимые подмножества не строятся: на практике состояний
у ДКА обычно немногим больше, чем у НКА, а не `2^n`.

Классический пример, где ДКА растёт экспоненциально: язык «n-й символ с конца — `a`». НКА имеет
`n + 1` состояние, минимальный ДКА — `2^n`, потому что должен помнить последние `n` символов.

## 4. ε-переходы

В общем случае НКА может иметь переходы без чтения символа (ε-переходы). Тогда при детерминизации
вместо множества `D` берут его **ε-замыкание** — все состояния, достижимые из `D` по одним
ε-стрелкам: `D0 = ε-closure({q0})`, `E = ε-closure(∪ t(p, a))`. Формат ЛР2 требует ровно
один символ в правиле, так что ε-переходов в наших файлах нет; строка `q1,=q2` считается ошибкой.

## 5. Висячие вершины

- **Недостижимое** состояние: нет пути из `q0`. Его правила никогда не сработают, его можно
  удалить без изменения языка. Находится обходом графа из `q0` (в ширину или в глубину).
- **Тупиковое** (бесполезное, «мёртвое») состояние: из него нет пути ни в одно конечное. Попав
  туда, автомат уже никогда не допустит строку. Находится обходом **против** стрелок из всех
  конечных состояний: кто не посещён — тупик. Бывает двух видов: без выходящих переходов вообще
  и «ловушка» — переходы есть, но по кругу.

Состояния, которые и достижимы, и из которых достижимо конечное, называют **полезными**.
Автомат, у которого все состояния полезны, называют приведённым. Если тупиком оказалось `q0`,
язык автомата пуст.

Пример кода из методички под «hangs» понимает более узкую вещь: переход в `q`-состояние,
у которого нет ни одного своего правила. Это частный случай тупика.

## 6. Минимизация (для общего понимания)

Детерминизация не даёт минимальный ДКА. Минимизация:

1. удалить недостижимые состояния;
2. разбить состояния на классы эквивалентности: сначала два класса — `F` и `Q \ F`; затем
   класс дробится, если два его состояния по какому-то символу уходят в разные классы;
   повторять, пока разбиение меняется (алгоритм Мура; Хопкрофт делает то же за `O(n log n)`);
3. каждый класс — одно состояние минимального ДКА.

Минимальный ДКА для языка единственен с точностью до имён состояний (теорема Майхилла — Нероуда).
В ДКА для `var3_nd.txt` состояния `f2 = {q5,f1}` и `q5`, например, не эквивалентны: `f2` конечное,
`q5` нет.

## 7. Связь с грамматиками

Регулярная (автоматная) грамматика и конечный автомат описывают один и тот же класс языков.
Правило `A → aB` даёт переход `t(A, a) ∋ B`, правило `A → a` — переход из `A` по `a` в конечное
состояние. Если у нетерминала есть два правила с одинаковым первым символом
(`S → a`, `S → aD`), автомат получается недетерминированным — так и устроен пример в методичке.
Конечные автоматы используются в компиляторе на этапе лексического анализа: распознают
идентификаторы, числа, ключевые слова (как автомат `for (...)` из приложения методички).
