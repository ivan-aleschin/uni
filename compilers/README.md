# Теория алгоритмических языков и компиляторов (ТАЯК)

Шесть лабораторных: от разбора арифметических выражений до интерпретатора и процессора
языка разметки. Методички — `.doc` из архива кафедры, для репозитория сконвертированы
в `.docx` (680 КБ → 160 КБ, содержимое и рисунки те же).

Языки реализации: **Python 3.14** во всех лабах. Для ЛР1–4 есть ещё запасная версия
на **C++20** (стандартный язык преподавателя) — она целиком лежит в подпапке `cpp/` лабы
со своими отчётом, шпаргалкой и тестами и даёт тот же результат. Корень лабы — только
Python-версия, сдаётся она.

| Лаба | Тема | Срок для нашей группы |
| --- | --- | --- |
| [`lab-1`](./lab-1) | Синтаксический анализатор и калькулятор выражений (обратная польская запись) | 3–17 сентября (у других групп до 1 октября) |
| [`lab-2`](./lab-2) | Конечные автоматы, детерминизация | 1 октября |
| [`lab-3`](./lab-3) | Магазинные (МП) автоматы по грамматике | 29 октября |
| [`lab-4`](./lab-4) | Синтаксический анализатор C-light с восстановлением после ошибок | 26 ноября |
| [`lab-5`](./lab-5) | Интерпретатор языка CBAS | 10 декабря |
| [`lab-6`](./lab-6) | Процессор языка разметки eMark | 24 декабря |

В папке каждой лабы: методичка `ТАЯК_ЛРN.docx`, код, отчёт `README.md`
и шпаргалка `SUMMARY.md` (суть, как рассказывать, вопросы, код по блокам).
`THEORY.md` есть только там, где тема не помещается в шпаргалку.

## Как запустить

```bash
cd ~/repos/uni
direnv allow                       # один раз; python3, g++ и make из flake появятся в PATH
cd compilers/lab-1
python3 main.py                    # Python-версия (точные аргументы — в README лабы)
cd cpp && make && ./lab1           # запасная C++-версия ЛР1–4 (см. cpp/README.md)
```

Без direnv: `nix develop -c python3 main.py` / `nix develop -c make` из папки лабы.

## Положения по предмету (со слов преподавателя)

### Автомат

Чтобы получить автомат, лабы нужно сдать определённым образом:

- **либо** ЛР4 на 4/5, а всё остальное на 5;
- **либо** ЛР4 на 5/5, и тогда любые две другие лабы можно сдать на 4/5;
- **плюс** все 4 семинара сданы хотя бы на 3/5.

Если посещение лекций не будет выставляться, Кремер поставит оценку по лабам.
Отдельные вопросы обсуждаются индивидуально.

### Экзамен

Автоматы выставят либо до Нового года, либо после выхода с каникул. Лектор тоже может
выдавать автоматы. На экзамене, возможно, будут трое: Манилов, Кремер, Дорогов.

### Языки

Можно делать на языке, на котором работаешь.

### Что в каждой лабе

1. **ЛР1** — проверить, правильная ли запись выражения, и выдать результат.
   Строки методички про файл «Преамбула.doc» не действуют: файла больше нет.
2. **ЛР2** — конечные автоматы, две части: первую делаешь сам, вторую — на сдаче, Кремер рисует
   автоматы на доске. С каждым днём сдачи автоматы усложняются, поэтому со сдачей не тянуть.
3. **ЛР3** — магазинные автоматы, ничего необычного.
4. **ЛР4** — синтаксический анализатор упрощённого языка; можно расширять язык своей грамматикой.
   Кто правильно сделает ЛР3, тому ЛР4 будет лёгкой (иначе это самая сложная лаба).
5. **ЛР5** — интерпретатор; можно (нужно?) использовать язык из ЛР4. Здесь сделан CBAS
   из методички.
6. **ЛР6** — процессор языка разметки; можно использовать любой язык разметки, не только
   указанный в лабе (например, HTML). Здесь сделан eMark из методички.
