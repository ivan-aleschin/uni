# Ход разбора: arr_init.cl

Грамматика: с массивами (--arrays), восстановление: режим фразы.

## Исходный текст

```c
// Синтаксические ошибки в объявлении и инициализации массивов.
// флаги: --arrays
// ожидается: panic=6 phrase=6
int main() {
    int a[3 = {1, 2, 3};
    int b[4] = {1 2, 3};
    int c[2] = {1, 2;
    int d[x];
    int e[3] = {};
    int f[2] = {1, 2,};
    return 0;
}
// Ошибки: 5 — нет ']', 6 — нет ',' между 1 и 2, 7 — нет '}', 8 — размер не число,
// 9 — пустой список инициализации, 10 — ',' перед '}'.
```

## Ошибки (6)

1. 5:12 — синтаксическая [пропущен символ]: ожидалось: ']' перед '='
2. 6:18 — синтаксическая [пропущен символ]: ожидалось: ',' перед '2'
3. 7:21 — синтаксическая [неполная конструкция]: перед ';' ожидалось: продолжение списка значений ('}', ',')
4. 8:11 — синтаксическая [неверный размер массива]: 'x': размер массива должен быть числом
5. 9:17 — синтаксическая [неполная конструкция]: перед '}' ожидалось: значение (идентификатор, число)
6. 10:22 — синтаксическая [неполная конструкция]: перед '}' ожидалось: значение (идентификатор, число)
