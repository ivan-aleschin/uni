# Ход разбора: arr_access.cl

Грамматика: с массивами (--arrays), восстановление: режим паники.

## Исходный текст

```c

// флаги: --arrays
// ожидается: panic=5 phrase=5

    int a[3] = {1, 2, 3};
    a[1 = 5;
    a[] = 2;
    int x = a[1][2];
```

## Ошибки (5)

1. 6:8 — синтаксическая [пропущен символ]: ожидалось: ']' перед '='
2. 7:7 — синтаксическая [неполная конструкция]: перед ']' ожидалось: индекс (идентификатор, число)
3. 8:17 — синтаксическая [неожиданный символ]: '[', ожидалось: ';'
4. 9:12 — синтаксическая [пропущен символ]: ожидалось: ']' перед '<'
5. 10:9 — синтаксическая [пропущен символ]: ожидалось: '=' перед '4'
