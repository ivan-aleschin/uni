# Ход разбора: err_block.cl

Грамматика: из методички, восстановление: режим фразы.

## Исходный текст

```c
// В грамматике из методички блок содержит ровно один оператор,
// поэтому второе объявление — ошибка (с флагом --ext — нет, см. ext_ok.cl).
// ожидается: panic=1 phrase=1
int main() {
    int a = 1;
    int b = 2;
}
```

## Ошибки (1)

1. 6:5 — синтаксическая [неожиданный символ]: 'int', ожидалось: '}' (в C-light блок { } содержит ровно один оператор; последовательности — расширение --ext)
