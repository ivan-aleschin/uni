# Ход разбора: err_brace.cl

Грамматика: из методички, восстановление: режим паники.

## Исходный текст

```c
// Только закрывающая скобка: нет ни заголовка main, ни тела.
// ожидается: panic=1 phrase=1
}
```

## Ошибки (1)

1. 3:1 — синтаксическая [неполная конструкция]: перед '}' ожидалось: тип ('int', 'bool', 'void')

## Таблица разбора

Стек: дно `$` слева, вершина справа. Вход: текущий токен первый, длинный хвост сокращён до 10 токенов.

| №   | Стек                                | Вход  | Примечание                                                                                                                              |
|-----|-------------------------------------|-------|-----------------------------------------------------------------------------------------------------------------------------------------|
| 1   | `$ <program>`                       | `} $` | `M[<program>, }]` пусто, у `<program>` одна продукция — раскрываем её по умолчанию: `<program> → <type> main ( ) { <statement> }`       |
| 2   | `$ } <statement> { ) ( main <type>` | `} $` | Ошибка 1 (неполная конструкция: перед '}' ожидалось: тип ('int', 'bool', 'void')), `M[<type>, }]` = synch → `<type>` снимается со стека |
| 3   | `$ } <statement> { ) ( main`        | `} $` | восстановление → снимаем 'main' со стека                                                                                                |
| 4   | `$ } <statement> { ) (`             | `} $` | восстановление → снимаем '(' со стека                                                                                                   |
| 5   | `$ } <statement> { )`               | `} $` | восстановление → снимаем ')' со стека                                                                                                   |
| 6   | `$ } <statement> {`                 | `} $` | восстановление → снимаем '{' со стека                                                                                                   |
| 7   | `$ } <statement>`                   | `} $` | `<statement> → ε`                                                                                                                       |
| 8   | `$ }`                               | `} $` | совпадение '}'                                                                                                                          |
| 9   | `$`                                 | `$`   | Разбор завершён, синтаксических ошибок: 1                                                                                               |
