# Ход разбора: err_header.cl

Грамматика: из методички, восстановление: режим паники.

## Исходный текст

```c
// Заголовок main без типа и без ')'.
// ожидается: panic=2 phrase=2
main( {
    return 0;
}
```

## Ошибки (2)

1. 3:1 — синтаксическая [неполная конструкция]: перед 'main' ожидалось: тип ('int', 'bool', 'void')
2. 3:6 — синтаксическая [пропущен символ]: ожидалось: ')' перед '{'

## Таблица разбора

Стек: дно `$` слева, вершина справа. Вход: текущий токен первый, длинный хвост сокращён до 10 токенов.

| №   | Стек                                | Вход                      | Примечание                                                                                                                                    |
|-----|-------------------------------------|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
| 1   | `$ <program>`                       | `main ( { return 0 ; } $` | `M[<program>, main]` пусто, у `<program>` одна продукция — раскрываем её по умолчанию: `<program> → <type> main ( ) { <statement> }`          |
| 2   | `$ } <statement> { ) ( main <type>` | `main ( { return 0 ; } $` | Ошибка 1 (неполная конструкция: перед 'main' ожидалось: тип ('int', 'bool', 'void')), `M[<type>, main]` = synch → `<type>` снимается со стека |
| 3   | `$ } <statement> { ) ( main`        | `main ( { return 0 ; } $` | совпадение 'main'                                                                                                                             |
| 4   | `$ } <statement> { ) (`             | `( { return 0 ; } $`      | совпадение '('                                                                                                                                |
| 5   | `$ } <statement> { )`               | `{ return 0 ; } $`        | Ошибка 2 (пропущен символ: ожидалось: ')' перед '{') → снимаем ')' со стека                                                                   |
| 6   | `$ } <statement> {`                 | `{ return 0 ; } $`        | совпадение '{'                                                                                                                                |
| 7   | `$ } <statement>`                   | `return 0 ; } $`          | `<statement> → <return>`                                                                                                                      |
| 8   | `$ } <return>`                      | `return 0 ; } $`          | `<return> → return num ;`                                                                                                                     |
| 9   | `$ } ; num return`                  | `return 0 ; } $`          | совпадение 'return'                                                                                                                           |
| 10  | `$ } ; num`                         | `0 ; } $`                 | совпадение '0'                                                                                                                                |
| 11  | `$ } ;`                             | `; } $`                   | совпадение ';'                                                                                                                                |
| 12  | `$ }`                               | `} $`                     | совпадение '}'                                                                                                                                |
| 13  | `$`                                 | `$`                       | Разбор завершён, синтаксических ошибок: 2                                                                                                     |
