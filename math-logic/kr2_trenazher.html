Тренажёр ко второй КР по математической логике

Задачи с полными решениями под спойлерами. Структура и сложность — по демоверсии: ординалы · запись формулой · значение в модели · дерево истинности. Сначала прорешай сам, потом раскрой решение.

Как пользоваться: каждая задача — это «нажми «Решение», только когда сам попробовал». Спойлеры (▸ Решение) раскрываются кликом. Уровень сложности нарастает внутри каждого блока.

Блок 1 · Ординалы и нормальная форма Кантора

Опорные правила:
  • Поглощение в сумме: при a < b  ωa·m + ωb·n = ωb·n (младшее слева гибнет).
  • Сбор подобных: ωa·m + ωa·n = ωa·(m+n).
  • Левая дистрибутивность: α·(β+γ) = α·β + α·γ. Правая — нет: (ω+1)·2 ≠ ω·2+1·2.
  • (конечное)·ω = ω,  (ω+k)·ω = ω²,  вообще α·ω = ω(старшая степень α)+1 для α с конечным старшим коэффициентом.
  • 1+ω = ω,  ω+1 ≠ ω;  (ω+1)^ω = ω^ω.
1.1. Привести к НФК: ω·3 + ω·2
▸ Решение
Одинаковая степень ω¹, складываем коэффициенты: ω·3 + ω·2 = ω·(3+2) = ω·5.
Не путать с умножением: коэффициенты складываются только при сложении подобных. И порядок важен — 3·ω + 2·ω это уже ω+ω = ω·... нет: 3·ω = ω, 2·ω=ω, сумма ω+ω = ω·2. Совсем другой результат!
Ответ: ω·5
1.2. Привести к НФК: 5 + ω + 3 + ω²
▸ Решение
Идём слева направо, применяя поглощение.
5 + ω = ω (конечное слева от ω гибнет).
ω + 3 = ω+3 (конечное справа НЕ гибнет — остаётся).
(ω+3) + ω² = ω² (всё, что слева от ω² и меньше его, поглощается).
Ответ: ω²
1.3. Привести к НФК: ω·2 + 2·ω²
▸ Решение
2·ω² = (2·ω)·ω = ω·ω = ω² (двойка слева от ω поглощается).
Теперь ω·2 + ω²: степень 1 слева от степени 2 → поглощается.
Ответ: ω²
1.4. Привести к НФК: (ω + 2)·(ω + 1)·ω  (задача из демоверсии)
▸ Решение
Умножение левоассоциативно: считаем ((ω+2)·(ω+1))·ω.
Шаг 1. (ω+2)·(ω+1) по левой дистрибутивности (раскрываем правый множитель ω+1):
(ω+2)·(ω+1) = (ω+2)·ω + (ω+2)·1
(ω+2)·ω = ω²  (на пределе старший член даёт ω·ω).  (ω+2)·1 = ω+2.
Итого: ω² + ω + 2.
Шаг 2. (ω²+ω+2)·ω: при умножении на ω справа берётся предел, поднимающий старший член: ω²·ω = ω³, остальное поглощается.
Ответ: ω³
1.5. Привести к НФК: (ω + 1)·3
▸ Решение
Это правый множитель — конечный, дистрибутивность тут не работает, раскрываем как повтор:
(ω+1)·3 = (ω+1)+(ω+1)+(ω+1)
= ω+1+ω+1+ω+1. Каждое 1+ω = ω, поэтому внутренние единицы перед ω гибнут:
= ω + ω + ω + 1 = ω·3 + 1.
Ответ: ω·3 + 1
Сравни: (ω+1)·3 = ω·3+1, а вот 3·(ω+1) = 3·ω+3·1 = ω+3. Разные результаты — некоммутативность.
1.6. Привести к НФК: (ω + 2)2
▸ Решение
(ω+2)² = (ω+2)·(ω+2), раскрываем правый множитель:
= (ω+2)·ω + (ω+2)·2
(ω+2)·ω = ω².
(ω+2)·2 = (ω+2)+(ω+2) = ω+2+ω+2 = ω+ω+2 = ω·2+2 (двойка перед ω гибнет).
Ответ: ω² + ω·2 + 2
1.7. Привести к НФК: (ω + 2)3  (из доп. листа)
▸ Решение
Используем результат 1.6: (ω+2)² = ω²+ω·2+2. Умножаем ещё раз на (ω+2):
(ω²+ω·2+2)·(ω+2) = (ω²+ω·2+2)·ω + (ω²+ω·2+2)·2
Первый член: (ω²+ω·2+2)·ω = ω³ (старший ω² поднимается до ω³, хвост поглощается).
Второй член: (ω²+ω·2+2)·2 = (ω²+ω·2+2)+(ω²+ω·2+2). Склеиваем: хвост первого …+ω·2+2 стоит слева от ω² второго и поглощается → ω²+ω²+ω·2+2 = ω²·2 + ω·2 + 2.
Складываем оба: ω³ + (ω²·2 + ω·2 + 2) — степени уже убывают.
Ответ: ω³ + ω²·2 + ω·2 + 2
1.8. Привести к НФК: (ω + 1)ω+1  (из доп. листа, со звёздочкой)
▸ Решение
Ключевой факт: (ω+1)ω = ωω (предел (ω+1)n не «обгоняет» ωω, младшие добавки гибнут на пределе).
Разбиваем показатель: (ω+1)ω+1 = (ω+1)ω·(ω+1) = ωω·(ω+1).
Левая дистрибутивность: ωω·(ω+1) = ωω·ω + ωω·1 = ωω+1 + ωω.
Ответ: ωω+1 + ωω
Степени в показателях тоже подчиняются НФК: ω+1 > ω, поэтому члены записаны по убыванию.

Блок 2 · Формализация на языке логики предикатов

Используй только указанную сигнатуру. Если предиката ≤ нет — выражай через (< ∨ =); если > нет — меняй аргументы местами. «Ровно один» = существование + единственность.
2.1. «Ивану скучно.» (одноместный предикат Скучно, константа Иван)
▸ Решение
Простое атомарное высказывание, кванторы не нужны.
Скучно(Иван)
Ответ: B(i), где B(x) — «x скучно», i — Иван
2.2. «Иванов и Петров играют в шахматы (друг с другом).»
▸ Решение
Двухместный предикат «играют в шахматы»: Ш(x,y).
Ш(Иванов, Петров)
Если имеется в виду «оба играют в шахматы (вообще)», то одноместный предикат: Ш(Иванов) ∧ Ш(Петров). Смысл «друг с другом» требует двухместного — уточни по лекции.
Ответ: Ш(Иванов, Петров)
2.3. «Каждый, кто упорно работает, добивается успеха.» (универсум — люди)
▸ Решение
«Каждый, кто P, тот Q» — классический шаблон ∀x (P(x) → Q(x)).
∀x (Работает(x) → Успех(x))
Частая ошибка — поставить ∧ вместо →: ∀x (Работает(x) ∧ Успех(x)) означало бы «все работают И все успешны», что неверно.
Ответ: ∀x (W(x) → S(x))
2.4. «Слон Бимбо больше собаки Ланды.» (предикат «больше» B(x,y), константы)
▸ Решение
Больше(Бимбо, Ланды)
Ответ: B(b, l)
2.5. «Кошки бывают только белые и серые.» (универсум — кошки)
▸ Решение
«Любая кошка либо белая, либо серая»:
∀x (Белый(x) ∨ Серый(x))
Если универсум — все животные, добавляем посылку: ∀x (Кошка(x) → (Белый(x) ∨ Серый(x))).
Ответ: ∀x (W(x) ∨ G(x))
2.6. «Уравнение x² − 3x + 2 = 0 не имеет решений.» (универсум — числа, есть = и арифметика)
▸ Решение
«Нет такого x, что …» = ¬∃x (или эквивалентно ∀x ¬).
¬∃x (x·x − 3·x + 2 = 0)
Эквивалентно: ∀x (x·x − 3·x + 2 ≠ 0), где ≠ — это ¬(…=…).
Ответ: ¬∃x (x²−3x+2 = 0)
Высказывание по факту ложно (корни 1 и 2), но формализация от истинности не зависит — переводим как есть.
2.7. «Есть максимальное число.» (универсум — целые, предикаты < и =; задача из демоверсии)
▸ Решение
Максимум = ничто не больше него = «для любого y неверно x < y».
∃x ∀y ¬(x < y)
Эквивалент через «≤»: ∃x ∀y (y < x ∨ y = x).
Порядок кванторов критичен: ∀y ∃x дало бы другое (ложное для ℤ) утверждение.
Ответ: ∃x ∀y ¬(x < y)
2.8. «Есть сколь угодно большие простые числа» (простых бесконечно много). (предикаты Prime(x), <)
▸ Решение
«Для любого числа найдётся простое, которое больше него»:
∀x ∃y (x < y ∧ Prime(y))
Ответ: ∀x ∃y (x < y ∧ Prime(y))
Сравни с «есть максимальное простое» (было бы ложью): ∃y (Prime(y) ∧ ∀z (Prime(z) → ¬(y < z))).
2.9. «У каждого положительного действительного числа есть ровно один положительный квадратный корень.» (Pos(x), предикат «y² = x» через умножение, =)
▸ Решение
«Ровно один» = существует И единствен. Шаблон ∃y (φ(y) ∧ ∀z (φ(z) → z = y)).
∀x ( Pos(x) → ∃y ( Pos(y) ∧ y·y = x ∧ ∀z ((Pos(z) ∧ z·z = x) → z = y) ) )
Читается: для каждого положительного x существует положительный y с y²=x, и любой другой положительный корень z совпадает с y.
Ответ: см. формулу выше (существование + единственность)
2.10. «Последовательность a₀, a₁, … имеет более одной предельной точки.» (предикат LP(x) — «x является предельной точкой», =)
▸ Решение
«Более одной» = существуют две различные предельные точки:
∃x ∃y ( LP(x) ∧ LP(y) ∧ x ≠ y )
где x ≠ y — сокращение для ¬(x = y).
Без условия x ≠ y формула ∃x∃y(LP(x)∧LP(y)) выполнялась бы и при одной точке (взяв x=y). Различие обязательно.
Ответ: ∃x ∃y (LP(x) ∧ LP(y) ∧ ¬(x=y))

Блок 3 · Значение формулы в конечной модели

В модели из k элементов: ∀x φ = конъюнкция φ по всем элементам (все должны быть И); ∃x φ = дизъюнкция (хоть один И). Сворачивай кванторы изнутри наружу. Для n кванторов — kⁿ наборов.
3.1. M = {a,b}, P(a)=0, P(b)=1. Найти ∀x∀y (P(x) ∨ P(y)). (демоверсия)
▸ Решение
xyP(x)P(y)P(x)∨P(y)
aa000
ab011
ba101
bb111
∀x∀y требует И во всех строках. Строка (a,a) даёт 0.
Ответ: 0 (ложь)
3.2. Та же модель. Найти ∃x∃y (P(x) ∧ P(y)).
▸ Решение
∃∃ = «хоть одна пара даёт И». Берём x=b, y=b: P(b)∧P(b) = 1∧1 = 1.
Ответ: 1 (истина)
3.3. Та же модель. Найти ∀x ∃y (P(x) → P(y)).
▸ Решение
Внешний ∀x: проверяем для x=a и x=b, что ∃y (P(x)→P(y)) истинно.
x=a: P(a)=0, тогда P(a)→P(y) = 0→… = 1 при любом y. ∃y истинно. ✓
x=b: P(b)=1, нужно ∃y P(b)→P(y) = 1→P(y) истинно. Берём y=b: 1→1=1. ✓
Оба значения x дали истину → ∀x истинно.
Ответ: 1 (истина)
3.4. M = {a,b}, P(a)=1, P(b)=0. Найти ∃x ∀y (P(x) → P(y)).
▸ Решение
∃x: достаточно найти один x, при котором ∀y (P(x)→P(y)) истинно.
x=a: P(a)=1. Нужно ∀y 1→P(y), т.е. P(y) для всех y. Но P(b)=0 → 1→0=0. Не годится.
x=b: P(b)=0. 0→P(y) = 1 для всех y. ∀y истинно. ✓
Нашли x=b → ∃x истинно.
Ответ: 1 (истина)
3.5. M = {1,2,3}, Q(x,y) истинно ⟺ x ≤ y. Найти ∀x ∃y Q(x,y).
▸ Решение
Для каждого x ищем y с x ≤ y.
x=1 → y=1,2,3 подходят ✓;   x=2 → y=2,3 ✓;   x=3 → y=3 ✓.
Для каждого x нашёлся y → ∀x∃y истинно.
Ответ: 1 (истина)
3.6. Та же модель {1,2,3}, Q(x,y) ⟺ x ≤ y. Найти ∃y ∀x Q(x,y).
▸ Решение
Меняется порядок кванторов: ищем один y, который ≥ всех x.
y=3: нужно ∀x (x ≤ 3) — верно для x=1,2,3. ✓
Ответ: 1 (истина — это y=3, наибольший элемент)
Здесь ∃y∀x и ∀x∃y оба истинны, но это совпадение из-за наличия максимума. В модели без максимума (как ℕ) ∀x∃y истинно, а ∃y∀x ложно — порядок кванторов меняет смысл!
3.7. M = {a,b}, R(a,a)=1, R(a,b)=1, R(b,a)=0, R(b,b)=1. Найти ∀x∀y (R(x,y) → R(y,x)) (симметричность).
▸ Решение
xyR(x,y)R(y,x)R(x,y)→R(y,x)

Пара (a,b): R(a,b)=1, но R(b,a)=0, импликация 1→0=0.
∀x∀y ложно из-за этой строки → отношение не симметрично.
Ответ: 0 (ложь)

Блок 4 · Дерево истинности (семантические таблицы)

Метод: посылки — истинны, заключение — ложно (приписываем ¬). Разворачиваем. Все ветви замкнулись (есть A и ¬A) → теорема. Осталась открытая ветвь → не теорема, из ветви читаем контрпример.

Кванторы: δ (∃-истинно / ∀-ложно) вводит свежую константу, один раз. γ (∀-истинно / ∃-ложно) подставляет любую существующую константу, можно много раз. Порядок: сначала δ, потом γ.
В деревьях: ✗ — замкнутая ветвь, ○ — открытая; c, d — введённые константы.
4.1. p → q, p ⊢ q  (modus ponens, чисто пропозиционально — разминка)
▸ Решение
1. p → q = И [посылка] 2. p = И [посылка] 3. ¬q [отрицание заключения] 4. β из 1 (правило →): ┌──────────┬──────────┐ ¬p q │ │ p и ¬p q и ¬q против. ✗ против. ✗ ✗ ✗
Обе ветви замкнулись.
Выводимо (теорема)
4.2. ⊢ ∀x P(x) → P(c)  (конкретизация)
▸ Решение
1. ¬(∀x P(x) → P(c)) = И [отрицаем заключение] 2. ∀x P(x) [из 1, правило ¬→] 3. ¬P(c) [из 1, правило ¬→] 4. γ из 2: подставляем c → P(c) 5. P(c) и ¬P(c) — противоречие ✗
Единственная ветвь замкнулась.
Выводимо (теорема)
4.3. ∃x (P(x) ∧ Q(x)) ⊢ ∃x P(x)
▸ Решение
1. ∃x (P(x) ∧ Q(x)) = И [посылка] 2. ¬∃x P(x) (= ∀x ¬P(x)) = И [отрицание заключения] 3. δ из 1: свежая c → P(c) ∧ Q(c) 4. α из 3 → P(c) 5. α из 3 → Q(c) 6. γ из 2: подставляем c → ¬P(c) 7. P(c) и ¬P(c) — противоречие ✗
Важен порядок: δ ввела c, затем γ подставила ту же c.
Выводимо (теорема)
4.4. ∀x (P(x) → Q(x)), ∀x P(x) ⊢ ∀x Q(x)
▸ Решение
1. ∀x (P(x) → Q(x)) = И [посылка] 2. ∀x P(x) = И [посылка] 3. ¬∀x Q(x) = И [отрицание заключения] 4. δ из 3: свежая c → ¬Q(c) 5. γ из 2: → P(c) 6. γ из 1: → P(c) → Q(c) 7. β из 6: ┌──────────┬──────────┐ ¬P(c) Q(c) │ │ P(c)&¬P(c) Q(c)&¬Q(c) против. ✗ против. ✗ ✗ ✗
Выводимо (теорема)
4.5. (∀x P(x)) → (∀x Q(x)) ⊢ ∀x (P(x) → Q(x))  (демоверсия)
▸ Решение
1. (∀x P(x)) → (∀x Q(x)) = И [посылка] 2. ¬∀x (P(x) → Q(x)) = И [отрицание заключения] 3. δ из 2: свежая c → ¬(P(c) → Q(c)) 4. α из 3 → P(c) 5. α из 3 → ¬Q(c) 6. β из 1: ┌────────────────────┬────────────────────┐ ¬∀x P(x) ∀x Q(x) │ │ δ: свежая d → ¬P(d) γ: подставляем c → Q(c) │ │ на ветви: P(c),¬Q(c), Q(c) и ¬Q(c) ¬P(d) противоречие ✗ пары A/¬A для одной ✗ константы НЕТ → ОТКРЫТА ○

4.6. ∃x P(x), ∃x Q(x) ⊢ ∃x (P(x) ∧ Q(x))
▸ Решение
1. ∃x P(x) = И [посылка] 2. ∃x Q(x) = И [посылка] 3. ¬∃x (P(x) ∧ Q(x)) = И [= ∀x ¬(P(x)∧Q(x))] 4. δ из 1: свежая c → P(c) 5. δ из 2: свежая d → Q(d) (ДРУГАЯ константа — c уже занята!) 6. γ из 3 для c → ¬(P(c)∧Q(c)) → β: ¬P(c) | ¬Q(c) ┌──────────┬──────────┐ ¬P(c) ¬Q(c) │ │ P(c)&¬P(c) ✗ на ветви: P(c),Q(d),¬Q(c) ✗ нет противоречия пока γ из 3 для d → ¬(P(d)∧Q(d)) → β: ¬P(d) | ¬Q(d) ┌──────────┬──────────┐ ¬P(d) ¬Q(d) │ │ P(c),Q(d), Q(d)&¬Q(d) ✗ ¬Q(c),¬P(d) ✗ нет пары → ОТКРЫТА ○

4.7. ∀x (P(x) ∧ Q(x)) ⊢ (∀x P(x)) ∧ (∀x Q(x))
▸ Решение
1. ∀x (P(x) ∧ Q(x)) = И [посылка] 2. ¬((∀x P(x)) ∧ (∀x Q(x))) = И [отрицание заключения] 3. β из 2 (¬∧): ┌────────────────┬────────────────┐ ¬∀x P(x) ¬∀x Q(x) │ │ δ: свежая c → ¬P(c) δ: свежая d → ¬Q(d) │ │ γ из 1 для c → γ из 1 для d → P(c) ∧ Q(c) P(d) ∧ Q(d) │ │ α → P(c), Q(c) α → P(d), Q(d) │ │ P(c) и ¬P(c) ✗ Q(d) и ¬Q(d) ✗ ✗ ✗

  • 1+ω=ω, ω+1≠ω; 2·ω=ω, ω·2≠ω.
  • Поглощение: меньшая степень слева от большей исчезает.
  • Левая дистрибутивность работает, правая — нет.
  • (ω+k)·ω = ω²; α·ω поднимает старшую степень α на +1.
  • НФК: степени ω убывают слева направо.

Запись формулой

  • «каждый P есть Q» → ∀x(P→Q) (импликация, не конъюнкция!).
  • «есть P, который Q» → ∃x(P∧Q) (конъюнкция, не импликация!).
  • «ровно один» → ∃x(φ(x) ∧ ∀y(φ(y)→y=x)).
  • «больше» при наличии только < → меняй аргументы; ≤ → (<∨=).
  • Порядок кванторов меняет смысл: ∀∃ ≠ ∃∀.

Значение в модели

  • ∀ = И по всем (один ноль рушит); ∃ = ИЛИ по всем (одна единица спасает).
  • Сворачивай изнутри наружу, строй таблицу всех наборов.

Дерево истинности

  • Посылки = И, заключение = Л.
  • α (не ветвит): ∧И, ¬∨, ¬→, ¬¬. β (ветвит): ∨И, →И, ¬∧.
  • δ свежая константа (∃И, ∀Л); γ любая существующая (∀И, ∃Л). Сначала δ!
  • Все ветви ✗ → теорема. Открыта ○ → контрпример (выпиши модель).
