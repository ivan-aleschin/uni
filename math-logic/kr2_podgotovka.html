1 · Ординалы и нормальная форма Кантора

Что такое ординалы

Порядковые числа (ординалы) — это «бесконечные номера», расширяющие натуральный ряд. После всех натуральных 0, 1, 2, … идёт первый бесконечный ординал ω, затем ω+1, ω+2, …, ω·2, …, ω², …, ω^ω, …

Главная ловушка — арифметика не коммутативна. Порядок множителей и слагаемых меняет результат.
  • Сложение: 1 + ω = ω, но ω + 1 ≠ ω (у ω+1 есть наибольший элемент, у ω — нет).
  • Умножение: 2 · ω = ω, но ω · 2 = ω + ω ≠ ω.
Читается «слева направо как размер»: ω·2 = «ω, взятое 2 раза» = ω+ω. А 2·ω = «двойка, взятая ω раз» = 2+2+2+… = ω.

Нормальная форма Кантора (НФК)

Любой ординал единственным образом записывается как сумма убывающих степеней ω с натуральными коэффициентами:

ωβ₁·c₁ + ωβ₂·c₂ + … + ωβₖ·cₖ ,   где β₁ > β₂ > … > βₖ ≥ 0

Это прямой аналог записи обычного числа по разрядам: старшие степени слева, коэффициенты — «цифры». Цель упрощения — привести выражение именно к такому виду: степени строго убывают, подобные слагаемые собраны.

Правила, которые нужны для упрощения

  • Поглощение при сложении: если α < β, то ωα·a + ωβ·b = ωβ·b. Младшая степень слева от старшей исчезает.
  • Сбор подобных: ωα·a + ωα·b = ωα·(a+b).
  • ω0 = 1, поэтому свободный (конечный) член — это ω0·c.
📌 Разбор задачи из варианта: упростить ω·2 + 2·ω²

Шаг 1. Раскрываем каждое произведение по определению.

  • ω·2 = ω + ω  (ω, взятое два раза). В терминах НФК это просто ω·2 = ω¹·2.
  • 2·ω² : здесь множитель 2 стоит слева от ω². Поскольку 2·ω = ω, то 2·ω² = (2·ω)·ω = ω·ω = ω². Двойка слева поглощается.

Шаг 2. Складываем, помня про поглощение.

ω·2 + 2·ω² = ω·2 + ω²

Слева стоит ω·2 (степень 1), справа ω² (степень 2). Младшая степень слева от старшей поглощается:

ω·2 + ω² = ω²
Ответ: ω²
Интуиция: ω·2 — это «всего лишь» две копии ω, а ω² — это ω копий ω, что неизмеримо длиннее. Когда короткий кусок стоит перед длинным, он растворяется в начале и не виден в итоговом порядковом типе. Если бы порядок был обратный (ω² + ω·2), ответ был бы ω² + ω·2 — здесь уже ничего не поглощается, потому что меньшее стоит справа.
Алгоритм для любого такого задания:
  1. Раскрой все произведения, используя конечное·ω = ω (двойки/тройки слева от ω гибнут).
  2. Выпиши слагаемые и определи степень ω у каждого.
  3. Иди слева направо: всякое слагаемое, у которого справа стоит слагаемое со строго большей степенью, вычёркивай.
  4. Оставшиеся подобные (одинаковая степень) собери, сложив коэффициенты.
  5. Проверь: степени строго убывают слева направо — это и есть НФК.

2 · Запись утверждения формулой логики предикатов

Задание: записать «есть максимальное число». Универсум — целые числа, сигнатура — только предикаты < и = (никаких функций и констант).

Как переводить русский в кванторы

  • «есть / существует» → ∃
  • «для любого / все / каждый» → ∀
  • «максимальный x» = «никакой y не больше x» = «для всех y верно, что не (x < y)».

Основной ответ

∃x ∀y  ¬(x < y)

Читается: существует такой x, что для любого y неверно, что x меньше y. То есть x — это потолок, выше которого ничего нет.

Эквивалентные допустимые записи

∃x ∀y  (y < x  ∨  y = x)

«Существует x, не меньший любого y» (любой y либо меньше x, либо равен ему). Тоже корректно и использует только < и =.

Частые ошибки:
  • Перепутать кванторы местами. ∀y ∃x ¬(x<y) означает совсем другое («для каждого y найдётся свой x») — это не «есть максимум».
  • Использовать символы вне сигнатуры (≤, +, числа). Раз их нет — выражай ≤ через (< ∨ =), а > через перестановку аргументов <.
  • Записать x > y. Символа > нет — пиши y < x.
Шаблоны, которые стоит выучить наизусть (универсум — числа, предикаты <, =):
УтверждениеФормула
есть максимум∃x ∀y ¬(x < y)
есть минимум∃x ∀y ¬(y < x)
нет максимума (как у ℤ)∀x ∃y (x < y)
между любыми двумя есть третье (плотность)∀x ∀y (x < y → ∃z (x < z ∧ z < y))

3 · Значение формулы в конечной модели

Дано: модель M = {a, b}, P(a) = 0, P(b) = 1. Найти значение ∀x ∀y (P(x) ∨ P(y)).

Как считать кванторы в конечной модели

  • ∀x φ(x) = конъюнкция по всем элементам: φ(a) ∧ φ(b). Истинно, только если для всех элементов истинно. Один ноль — и весь ∀ ложен.
  • ∃x φ(x) = дизъюнкция по всем элементам: φ(a) ∨ φ(b). Истинно, если хотя бы для одного истинно.
Поскольку кванторов два (∀x∀y), перебираем все пары (x, y): их 2×2 = 4.

Таблица перебора

xyP(x)P(y)P(x) ∨ P(y)
aa000
ab011
ba101
bb111

∀x∀y требует, чтобы P(x)∨P(y) было истинно во всех четырёх строках. Но в строке (a, a) значение равно 0.

∀x ∀y (P(x) ∨ P(y)) = 0 (ложь)
Ответ: ложь
Тонкость про область действия квантора. Если в варианте формула записана как ∀x∀y P(x) ∨ P(y) без скобок, важно понять, докуда «дотягивается» квантор. По стандартному соглашению квантор связывает как можно меньше, поэтому ∀x∀y P(x) ∨ P(y) формально читается как (∀x∀y P(x)) ∨ P(y) — и тогда последний y свободен, а значение зависит от его означивания. На КР почти всегда подразумевают вариант со скобками ∀x∀y (P(x) ∨ P(y)), как разобрано выше. Если скобок нет — напиши обе трактовки, это покажет понимание области действия и подстрахует.
Алгоритм:
  1. Выпиши значения предиката на всех элементах (P(a)=0, P(b)=1).
  2. Определи, сколько кванторов и какие — посчитай число строк (k элементов, n кванторов → kⁿ строк).
  3. Построй таблицу всех наборов, вычисли подформулу под кванторами.
  4. ∀ = «все строки истинны»; ∃ = «хотя бы одна истинна». Сворачивай кванторы изнутри наружу.

4 · Дерево истинности (семантические таблицы) для логики предикатов

Это то же самое аналитическое дерево, что было в задаче 1 первой КР, но теперь добавляются правила для кванторов ∀ и ∃. Самая объёмная тема — разбираю подробно.

Идея метода

Чтобы проверить выводимость Γ ⊢ φ, предполагаем, что посылки истинны, а заключение ложно, и раскладываем формулы по правилам. Если все ветви замкнулись (в каждой нашлись A и ¬A) — противоречие, значит вывод верен (это теорема). Если хоть одна ветвь осталась открытой — из неё читается контрпример, вывод неверен.

Правила разложения (пропозициональная часть)

ФормулаТипЧто делаем
A ∧ B истинноα (без ветвления)добавляем A и B в ту же ветвь
A ∨ B истинноβ (ветвление)две ветви: A | B
A → B истинноβ (ветвление)две ветви: ¬A | B
¬(A ∧ B)βдве ветви: ¬A | ¬B

Правила для кванторов — это главное в этой теме

∀x P(x) истинно
¬∃x P(x)		 γ (универсальное) Можно подставить любую константу, в том числе уже использованную. Применяется многократно — для каждой константы, которая появилась в ветви.

Порядок применения: сначала δ (вводят свежие константы), потом γ (подставляем в них). Иначе можно «промахнуться» мимо нужной константы.
Обозначения ниже: ⊤/⊥ помечаю явно; ✗ — замкнутая ветвь; ○ — открытая ветвь (даёт контрпример); c, d — введённые константы.
📌 Задача из варианта: (∀x P(x)) → (∀x Q(x)) ⊢ ∀x (P(x) → Q(x))

Предположение для дерева: посылка истинна, заключение ложно.

1. (∀x P(x)) → (∀x Q(x)) = И [посылка] 2. ¬∀x (P(x) → Q(x)) = И [отрицание заключения] Из 2 (δ-правило: ¬∀ ⇒ ∃ ¬, вводим свежую константу c): 3. ¬(P(c) → Q(c)) 4. P(c) [из 3, правило ¬→] 5. Q(c) ложно, т.е. ¬Q(c) [из 3, правило ¬→] Из 1 (β-правило для →, две ветви): ┌────────────────────────────┬────────────────────────────┐ 6а. ¬∀x P(x) 6б. ∀x Q(x) (левая ветвь) (правая ветвь) │ │ δ: вводим свежую d: γ: подставляем c: 7а. ¬P(d) 7б. Q(c) │ │ на ветви: P(c), ¬Q(c), ¬P(d) на ветви: P(c), ¬Q(c), Q(c) │ │ нет пары A/¬A для одной Q(c) и ¬Q(c) — противоречие константы → ветвь ОТКРЫТА → ветвь ЗАМКНУТА ✗ ○
Левая ветвь осталась открытой. На ней совместимы: P(c)=И, Q(c)=Л, и ¬P(d) — то есть существует элемент d, для которого P ложно. Это контрпример: вывод неверен.

Явный контрпример (его стоит выписать на КР)

Берём модель M = {c, d} со значениями:

элементPQ
c10
d00

Проверяем посылку и заключение:

  • ∀x P(x): P(d)=0 ⇒ ∀x P(x) = 0 (ложно).
  • Тогда посылка (∀x P(x)) → (∀x Q(x)) = (0 → …) = 1 — истинна вакуумно. ✓
  • Заключение ∀x (P(x)→Q(x)): для x=c имеем P(c)→Q(c) = 1→0 = 0 ⇒ всё ∀ ложно. ✓

Посылка истинна, а заключение ложно — значит ⊢ не выполняется.

Утверждение НЕ выводимо (опровергнуто, найден контрпример)
Почему интуитивно неверно: «если все P, то все Q» (1) гораздо слабее, чем «для каждого: из P следует Q» (2). Импликация (1) истинна и тогда, когда не все P (посылка ложна → импликация автоматически истинна), при этом отдельный элемент может иметь P, но не иметь Q. Обратная выводимость, кстати, верна: ∀x (P(x)→Q(x)) ⊢ (∀x P(x)) → (∀x Q(x)).
📌 Тренировка (теорема): ∀x (P(x) → Q(x)), ∀x P(x) ⊢ ∀x Q(x)
1. ∀x (P(x) → Q(x)) = И [посылка] 2. ∀x P(x) = И [посылка] 3. ¬∀x Q(x) = И [отрицание заключения] 4. δ из 3: вводим свежую c → ¬Q(c) 5. γ из 2: подставляем c → P(c) 6. γ из 1: подставляем c → P(c) → Q(c) 7. β из 6 (правило →): ┌──────────────┬──────────────┐ ¬P(c) Q(c) │ │ P(c) и ¬P(c) Q(c) и ¬Q(c) противоречие ✗ противоречие ✗ ✗ ✗

Обе ветви замкнулись ⇒ контрпримера нет.

Выводимо (это теорема)
📌 Тренировка (с ∃): ∃x (P(x) ∧ Q(x)) ⊢ ∃x P(x)
1. ∃x (P(x) ∧ Q(x)) = И [посылка] 2. ¬∃x P(x) = И [отрицание заключения = ∀x ¬P(x)] 3. δ из 1: свежая c → P(c) ∧ Q(c) 4. α из 3 → P(c) 5. α из 3 → Q(c) 6. γ из 2 (¬∃ = ∀¬, подставляем c) → ¬P(c) 7. P(c) и ¬P(c) — противоречие ✗ (единственная ветвь замкнута)
Выводимо (это теорема)
Обрати внимание на порядок: сначала δ из строки 1 ввела свежую c, и только потом γ из строки 2 подставила ту же c. Если бы сделали наоборот, пришлось бы угадывать константу.
Чек-лист для дерева с кванторами:
  1. Посылки — истинны, заключение — ложно (припиши ¬ к заключению).
  2. Сначала разворачивай δ (∃-истинно, ∀-ложно): каждая вводит свежую константу.
  3. Затем γ (∀-истинно, ∃-ложно): подставляй все уже имеющиеся константы, при необходимости несколько раз.
  4. Пропозициональные связки — по таблице α/β (α не ветвит, β ветвит).
  5. Ветвь замыкается, когда в ней есть A и ¬A для одной и той же подформулы/константы.
  6. Все ветви замкнуты → теорема. Осталась открытая → выпиши из неё контрпример (модель с конкретными значениями предикатов).
