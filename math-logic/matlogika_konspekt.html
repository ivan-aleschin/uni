1. Деревья истинности

Метод деревьев истинности позволяет проверить, является ли секвенция ψ₁, …, ψₙ ⊢ φ тавтологией. Идея: предполагаем, что посылки истинны, а заключение ложно — и ищем противоречие. Если противоречие есть на каждой ветке, секвенция доказана.

Условные обозначения:
φ ✓ — формула истинна  |  φ ✗ — формула ложна  |  ⊗ — ветка закрыта (противоречие)

Правила раскрытия

ФормулаЗнакЧто делаемВид
A ∧ B✓Оба истинны — на той же веткеA ✓, B ✓
A ∧ B✗Хоть один ложен — ветвлениеA ✗ | B ✗
A ∨ B✓Хоть один истинен — ветвлениеA ✓ | B ✓
A ∨ B✗Оба ложны — на той же веткеA ✗, B ✗
A → B✓Или A ложно, или B истинно — ветвлениеA ✗ | B ✓
A → B✗A истинно и B ложно — на той же веткеA ✓, B ✗
¬A✓A ложноA ✗
¬A✗A истинноA ✓
Ветка закрыта (⊗), если на ней одновременно встречаются φ ✓ и φ ✗ для одной и той же атомарной формулы φ.
Пример 1 — из тестового варианта
Доказать: ¬(p ∨ q) ⊢ ¬p ∨ ¬q

Записываем посылку ✓ и отрицание вывода ✗ (хотим найти противоречие):

1. ¬(p ∨ q) ✓ (посылка) 2. ¬p ∨ ¬q ✗ (отрицание заключения) Раскрываем (1) по правилу ¬A ✓ → A ✗: 3. p ∨ q ✗ Раскрываем (3) по правилу A ∨ B ✗ → оба ложны (на той же ветке): 4. p ✗ 5. q ✗ Раскрываем (2) по правилу A ∨ B ✗: 6. ¬p ✗ 7. ¬q ✗ Раскрываем (6) по ¬A ✗ → A ✓: 8. p ✓ ←→ противоречит (4): p ✗ ⊗ Единственная ветка закрылась → секвенция доказана. ✓
Пример 2
Доказать: p → q, q → r ⊢ p → r
1. p → q ✓ (посылка 1) 2. q → r ✓ (посылка 2) 3. p → r ✗ (отрицание заключения) Раскрываем (3) по → ✗: 4. p ✓ 5. r ✗ Раскрываем (1) по → ✓: ветвление / \ 6. p ✗ 6. q ✓ ⊗ (против. с 4) Раскрываем (2) по → ✓: ветвление / \ 7. q ✗ 7. r ✓ ⊗(против. с 6) ⊗(против. с 5) Все ветки закрыты → доказано. ✓

Когда секвенция НЕ доказана

Если хоть одна ветка осталась открытой (не закрылась), то секвенция ложна. Открытая ветка даёт конкретный контрпример — значения переменных на этой ветке делают посылки истинными, а заключение ложным.

2. Натуральная дедукция

Натуральная дедукция — это формальная система доказательств, где мы строим вывод шаг за шагом, применяя правила введения и удаления связок.

Формат записи

Каждая строка: номер. формула [обоснование]. Допущения открываются вертикальной чертой и закрываются правилом удаления.

Основные правила

ПравилоОбозначениеСмысл
Введение ∧∧IИз A и B получаем A ∧ B
Удаление ∧∧E₁, ∧E₂Из A ∧ B получаем A (или B)
Введение ∨ (левое)∨I₁Из A получаем A ∨ B (любое B)
Введение ∨ (правое)∨I₂Из B получаем A ∨ B (любое A)
Удаление ∨∨EИз A∨B, доказательств C из A и C из B → C
Введение →→IЕсли из допущения A вывели B, то доказан A → B
Удаление → (modus ponens)→EИз A → B и A получаем B
Введение ¬¬IЕсли из A получаем ⊥, то доказан ¬A
Удаление ¬ (¬¬)¬¬EИз ¬¬A получаем A
Введение ⊥⊥IИз A и ¬A получаем ⊥ (противоречие)
Удаление ⊥⊥EИз ⊥ получаем что угодно
Пример 1 — из тестового варианта
Доказать: (p ∨ q) ∨ r ⊢ p ∨ (q ∨ r)
1. (p ∨ q) ∨ r [посылка] 2. | p ∨ q [допущение для ∨E на стр. 1, левая ветка] 3. | | p [допущение для ∨E на стр. 2, левая ветка] 4. | | p ∨ (q ∨ r) [∨I₁ из 3] 5. | | q [допущение для ∨E на стр. 2, правая ветка] 6. | | q ∨ r [∨I₁ из 5] 7. | | p ∨ (q ∨ r) [∨I₂ из 6] 8. | p ∨ (q ∨ r) [∨E из 2, 3–4, 5–7] 9. | r [допущение для ∨E на стр. 1, правая ветка] 10. | q ∨ r [∨I₂ из 9] 11. | p ∨ (q ∨ r) [∨I₂ из 10] 12. p ∨ (q ∨ r) [∨E из 1, 2–8, 9–11] ■
Пример 2
Доказать: p → q ⊢ ¬q → ¬p
1. p → q [посылка] 2. | ¬q [допущение для →I] 3. | | p [допущение для ¬I] 4. | | q [→E из 1, 3] 5. | | ⊥ [⊥I из 2, 4: ¬q и q] 6. | ¬p [¬I из 3–5: из допущения p получили ⊥] 7. ¬q → ¬p [→I из 2–6] ■
Пример 3
Доказать: ⊢ p ∨ ¬p (закон исключённого третьего)

Этот закон требует классической логики (правило ¬¬E или reductio ad absurdum):

1. | ¬(p ∨ ¬p) [допущение для ¬I] 2. | | p [допущение для ¬I] 3. | | p ∨ ¬p [∨I₁ из 2] 4. | | ⊥ [⊥I из 1, 3] 5. | ¬p [¬I из 2–4] 6. | p ∨ ¬p [∨I₂ из 5] 7. | ⊥ [⊥I из 1, 6] 8. ¬¬(p ∨ ¬p) [¬I из 1–7] 9. p ∨ ¬p [¬¬E из 8] ■
Главное правило: когда закрываете допущение через ∨E, →I или ¬I — убедитесь, что нужный вам вывод уже получен внутри блока допущения.

3. Функции: вложения, наложения, биекции

Определения

Функция f: A → B — правило, сопоставляющее каждому a ∈ A ровно один элемент f(a) ∈ B.

Вложение (инъекция): f(x) = f(y) ⟹ x = y. («Разные входы — разные выходы»)
Эквивалентно: x ≠ y ⟹ f(x) ≠ f(y)

Наложение (сюръекция): ∀b ∈ B ∃a ∈ A: f(a) = b. («Каждый выход достигается»)

Биекция: f — и вложение, и наложение одновременно.

Стандартные конструкции

Тождественное отображение: idA: A → A, id(x) = x. Всегда биекция.
Декартово произведение: A × B = {(a, b) | a ∈ A, b ∈ B}
Степенное множество: 𝒫(A) = {X | X ⊆ A}
Композиция: (g ∘ f)(x) = g(f(x)), где f: A→B, g: B→C

Как доказывать и опровергать

Что доказываемМетод
f — вложениеПредположить f(x)=f(y), вывести x=y
f — НЕ вложениеНайти x≠y такие, что f(x)=f(y)
f — наложениеДля произвольного b∈B найти a∈A с f(a)=b
f — НЕ наложениеНайти b∈B, не лежащий в образе f
Пример 1 — из тестового варианта
f: ℕ → ℕ, f(n) = 2n + 3

а) Вложение? ДА

Пусть f(n) = f(m), т.е. 2n+3 = 2m+3. Вычитаем 3: 2n = 2m, делим на 2: n = m. ✓

б) Наложение? НЕТ

Контрпример: возьмём b = 1 ∈ ℕ. Если 2n+3 = 1, то n = −1 ∉ ℕ. Элемент 1 не достигается. ✗

Вообще f(ℕ) = {3, 5, 7, 9, …} — только нечётные числа ≥ 3.

Пример 2
f: ℝ → ℝ, f(x) = x²

Вложение? НЕТ — f(2) = f(−2) = 4, но 2 ≠ −2.

Наложение? НЕТ — f(x) ≥ 0, поэтому −1 ∈ ℝ не достигается.

Пример 3
i: A → B, i(x) = x (включение) — для каких A, B это вложение/наложение/биекция?
  • Функция: всегда (если A ⊆ B, иначе вообще не определена)
  • Вложение: всегда (i(x)=i(y) ⟹ x=y тривиально)
  • Наложение: только если A = B
  • Биекция: только если A = B

Теоремы о композиции (задача 7 из ДЗ)

Пусть f: A→B, g: B→C функции. Тогда:
• Если f и g — вложения, то g∘f — вложение.
• Если f и g — наложения, то g∘f — наложение.
• Если f и g — биекции, то g∘f — биекция.
Доказательство первого пункта

Пусть (g∘f)(x) = (g∘f)(y), т.е. g(f(x)) = g(f(y)).

g — вложение ⟹ f(x) = f(y).

f — вложение ⟹ x = y. ✓

Левая и правая обратная функция (задача 10 из ДЗ)

g: B→A называется левой обратной к f, если g∘f = idA, т.е. ∀a∈A: g(f(a)) = a.
g: B→A называется правой обратной к f, если f∘g = idB, т.е. ∀b∈B: f(g(b)) = b.
Теорема: f имеет левую обратную ⟺ f — вложение.
Теорема: f имеет правую обратную ⟺ f — наложение.
(Правое ⟹ наложение доказывается конструктивно; ⟸ требует аксиомы выбора)

Биекция между 𝒫(A) и A→{0,1} (задача 9 из ДЗ)

Построение явной биекции

Для каждого подмножества B ⊆ A определим его характеристическую функцию:

χB: A → {0,1},   χB(x) = 1 если x ∈ B, иначе 0

Отображение Φ: 𝒫(A) → (A→{0,1}), Φ(B) = χB — это биекция.

  • Вложение: если χB = χC, то для любого x: x∈B ⟺ χB(x)=1 ⟺ χC(x)=1 ⟺ x∈C, значит B = C.
  • Наложение: для любой f: A→{0,1} положим B = f⁻¹(1) = {x∈A | f(x)=1}, тогда χB = f.

Упорядоченная пара по Куратовскому (задача 12 из ДЗ)

Определение: (a, b) := {{a}, {a, b}}

Теорема: (a, b) = (c, d) ⟺ a = c и b = d.
Доказательство теоремы

Пусть {{a},{a,b}} = {{c},{c,d}}. Разберём случаи:

Одноэлементное множество {a} ∈ {{c},{c,d}}, значит {a} = {c} или {a} = {c,d}.

Случай 1: {a} = {c}. Тогда a = c. Двухэлементное {a,b} = {c,d} = {a,d}, значит b = d. ✓

Случай 2: {a} = {c,d}. Тогда c = d = a. Тогда {{c},{c,d}} = {{a},{a,a}} = {{a},{a}} = {{a}}, а {{a},{a,b}} = {{a}} означает {a} = {a,b}, т.е. b = a. Итого a=c, b=d. ✓

4. Теория множеств: мощности

Основные понятия

Множества A и B равномощны (|A| = |B|), если между ними существует биекция.

Счётные множества: |A| = |ℕ| = ℵ₀ (строго бесконечные счётные)
Мощность континуума: c = |ℝ| = |[0,1]| = |{0,1}ᴺ|
Теорема Кантора: |A| < |𝒫(A)| для любого A (мощность степенного множества всегда строго больше)

Пример 1 — из тестового варианта
Мощность множества всех многочленов с действительными коэффициентами

Обозначим Pn = множество всех многочленов степени ≤ n с действ. коэффициентами.

Многочлен степени ≤ n — это набор (a₀, a₁, …, aₙ) ∈ ℝⁿ⁺¹, т.е. |Pn| = |ℝⁿ⁺¹| = cⁿ⁺¹ = c (т.к. c²=c).

Всё множество многочленов = P₀ ∪ P₁ ∪ P₂ ∪ … — счётное объединение множеств мощности c.

Счётное объединение множеств мощности c имеет мощность c. Ответ: c

Пример 2 — задача 3 из ДЗ
|отрезок| = |интервал|, оба равны c

Строим явную биекцию между [0,1] и (0,1). Одна из стандартных конструкций:

Выберем счётное плотное подмножество S = {0, 1, ½, ⅓, ¼, …} ⊂ [0,1].
Перенумеруем S = {s₀, s₁, s₂, …} и пусть S' = {s₁, s₂, s₃, …} ⊂ (0,1).
Определим f: [0,1] → (0,1): f(sₙ) = sₙ₊₁, f(x) = x для x ∉ S.

Это биекция. Аналогично через арктангенс строится биекция (0,1) → ℝ.

Пример 3 — задача 2 из ДЗ
Алгебраические числа счётны

Алгебраическое число — действительный корень ненулевого многочлена с рациональными коэффициентами.

Шаг 1. Многочлены с рац. коэф. счётны (задача 1): пронумеруем их m₁, m₂, m₃, …

Шаг 2. Каждый многочлен mₙ степени d имеет не более d корней — конечное множество.

Шаг 3. Множество алгебраических чисел = ⋃ₙ {корни mₙ} — счётное объединение конечных множеств. Значит, оно счётно.

Пример 4 — задача 7 из ДЗ
Иррациональные числа имеют мощность c

Обозначим I = ℝ \ ℚ (иррациональные числа). Тогда ℝ = ℚ ∪ I.

Предположим |I| = ℵ₀. Тогда |ℝ| = |ℚ ∪ I| ≤ ℵ₀ + ℵ₀ = ℵ₀. Противоречие с |ℝ| = c > ℵ₀.

Предположим |I| < ℵ₀ (конечно). Тогда |ℝ| = |ℚ| + конечное = ℵ₀. Снова противоречие.

Значит |I| = c. Ответ: c

Пример 5 — задача 8 из ДЗ
Строго возрастающие бесконечные последовательности натуральных чисел — мощность c

Обозначим нашу коллекцию через S.

Биекция S → {бесконечные подмножества ℕ}:
Каждой строго возрастающей послед. (a₁ < a₂ < a₃ < …) сопоставим подмножество {a₁, a₂, a₃, …} ⊆ ℕ. Это биекция.

|{бесконечные подмножества ℕ}| = c, т.к. |𝒫(ℕ)| = 2ℵ₀ = c, и конечных подмножеств лишь ℵ₀, поэтому бесконечных — тоже c.

★ Задача 14 — c² = c
Доказать построением явной биекции, что |ℝ × ℝ| = |ℝ|

Достаточно построить биекцию (0,1) × (0,1) → (0,1) (тогда c² = c).

Метод чередования цифр:
Запишем x = 0.x₁x₂x₃… и y = 0.y₁y₂y₃… (в десятичной записи, без бесконечных девяток).
Определим f(x,y) = 0.x₁y₁x₂y₂x₃y₃…

Это инъекция (0,1)² → (0,1). В другую сторону: проекции на чётные/нечётные позиции дают (x,y). Итого биекция. c² = c ✓

★ Задача 15 — непрерывные функции ℝ→ℝ имеют мощность c
Ключевая идея из подсказки:

Если две непрерывные функции f и g совпадают на ℚ (рациональных числах), они совпадают всюду на ℝ.

Почему: ℚ плотно в ℝ. Для любого x∈ℝ найдём qₙ∈ℚ с qₙ→x. По непрерывности f(x) = lim f(qₙ) = lim g(qₙ) = g(x).

Следствие: непрерывная функция определяется своими значениями на ℚ, т.е. элементом ℝᴺ (т.к. |ℚ| = ℵ₀).

|ℝᴺ| = cℵ₀ = (2ℵ₀)ℵ₀ = 2ℵ₀·ℵ₀ = 2ℵ₀ = c.

С другой стороны, константные функции f(x)≡c уже дают c штук. Итого: мощность = c. ✓

Методы доказательства равномощности

  1. Явная биекция: строим конкретную f: A→B и доказываем, что она инъекция и сюръекция.
  2. Теорема Кантора–Бернштейна: если |A| ≤ |B| и |B| ≤ |A| (есть инъекция в обе стороны), то |A| = |B|.
  3. Счётное объединение счётных: ⋃ₙAₙ с |Aₙ|=ℵ₀ → |⋃Aₙ|=ℵ₀ (если индексов счётно).
  4. Счётное объединение мощности c: ⋃ₙAₙ с |Aₙ|=c → |⋃Aₙ|=c.
  5. Диагональный аргумент Кантора: для доказательства несчётности (например, ℝ).
