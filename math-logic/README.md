# Математическая логика и теория алгоритмов

Материалы по курсу **Математическая логика и теория алгоритмов** НИУ МИЭТ.

## Ресурсы

- 📚 [Материалы преподавателя](https://github.com/alexeyr/miet-logic-course) — лекции, семинары и домашние задания в PDF и LaTeX

## Советы

- **Деревья истинности** — всегда начинай с отрицания цели и ищи противоречие во всех ветках
- **Натуральная дедукция** — держи таблицу правил вывода перед глазами на каждом занятии
- **Теория множеств** — Верещагин и Шень, Часть 1 бесплатно доступна на сайте МЦНМО, объясняет всё очень понятно
