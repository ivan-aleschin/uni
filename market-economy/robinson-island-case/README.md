# Кейс «Остров Робинзона: кто здесь хозяин?»

**Задание:** [задание.docx](задание.docx) — проблемный кейс с ролевой игрой на группу из
4–5 человек (60–70 минут). Темы: экономический рост, экономические циклы, собственность
и её роль в экономических системах. Решаем впятером: Анна, Борис, Виктор, Галина, Дмитрий.

Шпаргалка для защиты — [SUMMARY.md](SUMMARY.md).

## Как собрать PDF

`direnv allow` в корне репозитория, затем в этой папке выполнить `make` (запасной вариант —
`nix develop -c make`). Получится `solution.pdf`.

---

## Решение

Решение по всем четырём этапам (4 страницы) — исходник на typst [solution.typ](solution.typ), PDF для
сдачи — [solution.pdf](solution.pdf).

| Этап | Наш ответ коротко |
| --- | --- |
| 1. «Правила игры» | смешанная экономика; земля, недра, озеро и лес принадлежат государству (мы арендатор), созданные объекты — частные или коллективные; первый год работают только пятеро, дальше вахтовики по квоте |
| 2. «Экономический рост» | комбинация: сначала экстенсивный рост (люди, земля, техника), с 6-го года — интенсивный; без диверсификации остров ждёт «голландская болезнь» |
| 3. «Кризис неизбежен» | фаза кризиса (спада), цикл Жюгляра; спасают стабфонд, общественные работы, переход к агро и IT |
| 4. «Суд собственников» | приватизация и национализация отклонены 1 : 4, компромисс принят 4 : 1; Борис не может продать недра — они государственные, распоряжаться ими он не вправе |
