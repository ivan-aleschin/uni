# Д.З.-3.1. Расчёт допусков размерной цепи для точного сопряжения

**Задание.** В качестве объекта анализа и синтеза точности размерных цепей принять
сопряжение, обозначенное в таблице вариантов как диаметральный размер d₄. Для варианта 1-А
d₄ = ∅4,5 E9-m5 (распорная втулка на валу).

Сопряжение рассматриваем как трёхзвенную размерную цепь: замыкающее звено A~Δ~ — зазор S,
составляющие звенья A₁ — диаметр отверстия D и A₂ — диаметр вала d.

![Схема размерной цепи сопряжения](fig/chain.svg){width=45%}

Уравнение размерной цепи: A~Δ~ = A₁ − A₂. Звено A₁ увеличивающее, ξ₁ = +1; звено A₂
уменьшающее, ξ₂ = −1. Номинальные значения A₁ = A₂ = 4,5 мм, тогда A~Δ~ = 4,5 − 4,5 = 0.

## 1. Обратная задача (анализ точности)

Предельные отклонения звеньев по ГОСТ 25346-2013 (интервал св. 3 до 6 мм), мкм.

Звено A₁ (отверстие ∅4,5E9): Δ~В1~ = +50; Δ~Н1~ = +20;\
Δ~С1~ = 0,5(Δ~В1~ + Δ~Н1~) = 0,5(50 + 20) = +35; T~1~ = 50 − 20 = 30.

Звено A₂ (вал ∅4,5m5): Δ~В2~ = +9; Δ~Н2~ = +4;\
Δ~С2~ = 0,5(9 + 4) = +6,5; T~2~ = 9 − 4 = 5.

**Метод максимума-минимума.** Допуск замыкающего звена

T~Δ~ = T₁ + T₂ = 30 + 5 = 35 мкм.

Координата середины поля допуска замыкающего звена

Δ~0Δ~ = ξ₁Δ~С1~ + ξ₂Δ~С2~ = 1·35 + (−1)·6,5 = +28,5 мкм.

Предельные отклонения замыкающего звена:

Δ~ВΔ~ = Δ~0Δ~ + 0,5·T~Δ~ = 28,5 + 0,5·35 = +46 мкм;\
Δ~НΔ~ = Δ~0Δ~ − 0,5·T~Δ~ = 28,5 − 0,5·35 = +11 мкм.

В условиях полной взаимозаменяемости $A_\Delta = 0^{\text{+0,046}}_{\text{+0,011}}$ мм, то есть
S~max~ = 46 мкм, S~min~ = 11 мкм.

**Теоретико-вероятностный метод.** Отклонения обоих звеньев распределены по
нормальному закону ($\lambda'^2 = 1/9$), коэффициент риска t~Δ~ = 3 (процент риска P = 0,27 %).
По формуле (3.15):

$$T_\Delta = t_\Delta\sqrt{{\lambda'_1}^2 T_1^2 + {\lambda'_2}^2 T_2^2} = 3\sqrt{\frac{1}{9}\left(30^2 + 5^2\right)} = \sqrt{925} = 30{,}41 \text{ мкм.}$$

Координата середины поля рассеяния не меняется: Δ~0Δ~ = +28,5 мкм. С вероятностью
P = 0,9973 зазоры находятся в пределах

Δ~ВΔ~ = 28,5 + 0,5·30,41 = +43,7 мкм; Δ~НΔ~ = 28,5 − 0,5·30,41 = +13,3 мкм,

$A_\Delta = 0^{\text{+0,0437}}_{\text{+0,0133}}$ мм.

## 2. Прямая задача (синтез точности)

Заданы параметры сопряжения: S~max~ = +46 мкм, S~min~ = +11 мкм, номинальный размер
D = d = 4,5 мм. Требуется найти допуски, координаты середин полей допусков и предельные
отклонения отверстия и вала.

Параметры замыкающего звена: Δ~ВΔ~ = +46 мкм; Δ~НΔ~ = +11 мкм;\
Δ~0Δ~ = 0,5(46 + 11) = +28,5 мкм; T~Δ~ = 46 − 11 = 35 мкм.

Параметры составляющих звеньев:

| j | A~j~, мм | Положение поля допуска | ξ~j~ | λ'²~j~ | Примечание |
| :---: | :---: | :---: | :---: | :---: | --- |
| 1 | 4,5 | отверстие | +1 | 1/6 | ↑ К |
| 2 | 4,5 | вал, Δ~Н2~ = +4 мкм | −1 | 1/3 | ↓ |

Примечания к таблице:

1) номинальные значения звеньев равны, поэтому расчёт ведём способом равных допусков;
2) изготовление отверстия сложнее и дороже, чем вала, поэтому допуск звена A₁
   увеличиваем (↑), а звена A₂ уменьшаем (↓);\
3) положение поля вала оставляем по основному отклонению m (Δ~Н2~ = +4 мкм),
   корректировку (К) положения поля замыкающего звена выполняем за счёт отверстия;\
4) законы распределения: для A₁ — закон Симпсона ($\lambda'^2 = 1/6$), для A₂ — закон
   равной вероятности ($\lambda'^2 = 1/3$); коэффициент риска t~Δ~ = 3 (P = 0,27 %).

**Метод максимума-минимума.** Среднее значение допуска по формуле (3.18):

$$T_{ср} = \frac{T_\Delta}{\sum |\xi_j|} = \frac{35}{2} = 17{,}5 \text{ мкм.}$$

Расширяем допуск отверстия за счёт вала: T~1~ = 20 мкм, T~2~ = 15 мкм.
Проверка по формуле (3.6): T~Δ~ = 20 + 15 = 35 мкм. Допуски назначены верно.

Вал: Δ~Н2~ = +4 мкм, Δ~В2~ = 4 + 15 = +19 мкм, Δ~02~ = 0,5(19 + 4) = +11,5 мкм.

Координату середины поля допуска отверстия находим из уравнения (3.2):
Δ~0Δ~ = ξ₁Δ~01~ + ξ₂Δ~02~, откуда Δ~01~ = 28,5 + 11,5 = +40 мкм.

Предельные отклонения отверстия:
Δ~В1~ = 40 + 0,5·20 = +50 мкм; Δ~Н1~ = 40 − 0,5·20 = +30 мкм.

Проверка: Δ~ВΔ~ = Δ~В1~ − Δ~Н2~ = 50 − 4 = +46 мкм; Δ~НΔ~ = Δ~Н1~ − Δ~В2~ = 30 − 19 = +11 мкм.
Задача решена верно.

Результат: отверстие $\varnothing 4{,}5^{\text{+0,050}}_{\text{+0,030}}$, вал $\varnothing 4{,}5^{\text{+0,019}}_{\text{+0,004}}$.

**Теоретико-вероятностный метод.** Среднее значение допуска по формуле (3.19):

$$T_{ср} = \frac{T_\Delta}{t_\Delta\sqrt{\sum \xi_j^2 {\lambda'_j}^2}} = \frac{35}{3\sqrt{1/6 + 1/3}} = \frac{35}{2{,}121} = 16{,}5 \text{ мкм.}$$

С тем же расширением допуска отверстия назначаем T~1~ = 20 мкм, T~2~ = 14 мкм.

Проверка (обратная задача теоретико-вероятностным методом):

$$T_\Delta = 3\sqrt{\frac{20^2}{6} + \frac{14^2}{3}} = 3\sqrt{66{,}67 + 65{,}33} = 34{,}47 \text{ мкм} \le 35 \text{ мкм,}$$

расхождение 1,5 %. Допуски назначены правильно.

Вал: Δ~Н2~ = +4 мкм, Δ~В2~ = 4 + 14 = +18 мкм, Δ~02~ = +11 мкм.

Отверстие: Δ~01~ = Δ~0Δ~ + Δ~02~ = 28,5 + 11 = +39,5 мкм;\
Δ~В1~ = 39,5 + 10 = +49,5 мкм; Δ~Н1~ = 39,5 − 10 = +29,5 мкм.

Проверка: Δ~0Δ~ = 39,5 − 11 = +28,5 мкм; с вероятностью 0,9973 зазор находится
в пределах 28,5 ± 0,5·34,47, то есть от +11,3 до +45,7 мкм, внутри заданных 11…46 мкм.
Задача решена верно.

Результат: отверстие $\varnothing 4{,}5^{\text{+0,0495}}_{\text{+0,0295}}$, вал $\varnothing 4{,}5^{\text{+0,018}}_{\text{+0,004}}$.

# Д.З.-3.2. Расчёт параметрической размерной цепи

**Задание.** Схема 1, вариант 1-1. Участок электрической схемы состоит из подстроечного
резистора r\*, резистора r₁ и трёх параллельно включённых резисторов r₂, r₃, r₄.
Общее сопротивление R = 32 ± 0,1; r₁ = 10 ± 1; r₂ = 80 ± 4; r₃ = 40 ± 2; r₄ = 8 ± 4.
Размерность всех сопротивлений — кОм. Рассчитать пределы регулировки подстроечного
резистора r\*′ и r\*″ при условии минимального диапазона регулировки.

![Электрическая схема соединения резисторов](fig/resistors.svg){width=60%}

**Решение.** Параметрическая размерная цепь: r~Δ~ = R — замыкающее звено (сопротивление
всего участка), r₁ и r~ab~ — составляющие звенья (r~ab~ — сопротивление участка ab
с параллельным соединением r₂, r₃, r₄), r\* — компенсирующее звено. Все отклонения
симметричны, поэтому номинальное значение r\* равно его среднему значению.

1) Сопротивление участка ab:

$$\frac{1}{r_{ab}} = \frac{1}{80} + \frac{1}{40} + \frac{1}{8} = 0{,}0125 + 0{,}025 + 0{,}125 = 0{,}1625; \qquad r_{ab} = 6{,}154 \text{ кОм.}$$

2) Предельное отклонение r~ab~. Коэффициент влияния каждого резистора
∂r~ab~/∂r~i~ = (r~ab~/r~i~)², тогда

$$\Delta r_{ab} = \left(\frac{r_{ab}}{r_2}\right)^2\Delta r_2 + \left(\frac{r_{ab}}{r_3}\right)^2\Delta r_3 + \left(\frac{r_{ab}}{r_4}\right)^2\Delta r_4,$$

$$\Delta r_{ab} = \left(\frac{6{,}154}{80}\right)^2 4 + \left(\frac{6{,}154}{40}\right)^2 2 + \left(\frac{6{,}154}{8}\right)^2 4,$$

$$\Delta r_{ab} = 0{,}024 + 0{,}047 + 2{,}367 = 2{,}438 \text{ кОм.}$$

r~ab~ = (6,15 ± 2,44) кОм.

3) Номинальное значение подстроечного резистора:

r\* = r~Δ~ − (r₁ + r~ab~) = 32 − (10 + 6,15) = 15,85 кОм.

4) Предельные значения r\* находим из задачи анализа точности методом
максимума-минимума:

r~Δ\ min~ = r~1\ min~ + r~ab\ min~ + r\*′, откуда
r\*′ = r~Δ\ min~ − (r~1\ min~ + r~ab\ min~) = 31,9 − (9 + 3,71) = 19,19 кОм;

r~Δ\ max~ = r~1\ max~ + r~ab\ max~ + r\*″, откуда
r\*″ = r~Δ\ max~ − (r~1\ max~ + r~ab\ max~) = 32,1 − (11 + 8,59) = 12,51 кОм.

5) Предельные значения и диапазон регулировки:

r\*~min~ = r\*″ = 12,51 кОм; r\*~max~ = r\*′ = 19,19 кОм;\
2·Δr\* = 19,19 − 12,51 = 6,68 кОм; Δr\* = 3,34 кОм; r\* = (15,85 ± 3,34) кОм.

6) Проверка заданного условия R = 32 ± 0,1 кОм:

r~Δ\ min~ = 9 + 3,71 + 19,19 = 31,90 кОм; r~Δ\ max~ = 11 + 8,59 + 12,51 = 32,10 кОм.

Найденные пределы регулировки подстроечного резистора обеспечивают сопротивление
участка в заданных пределах.

**Ответ:** пределы регулировки r\* от 12,51 до 19,19 кОм, r\* = (15,85 ± 3,34) кОм.
