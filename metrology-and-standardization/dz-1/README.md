## Задачи варианта 1

| № | Вид измерения | Что найти | Ответ |
| :---: | --- | --- | --- |
| 1 | прямое однократное | сопротивление нагрузки R, P = 0,95 | R = (7,36 ± 0,04) Ом |
| 2 | прямое многократное | диаметр валика d, P = 0,95 | d = (100,0001 ± 0,0013) мм |
| 3 | косвенное | ускорение свободного падения g по маятнику | g = (9,85601 ± 0,00027) м/с², P = 1 |

Коротко по ходу решения:

1. Задача 1: среднее из трёх показаний, предел основной погрешности из класса точности
   (0,2 % от 10 Ом = 0,02 Ом), методическая 0,03 Ом идёт второй составляющей НСП,
   Θ = 1,1·√(0,02² + 0,03²) = 0,0397 → 0,04 Ом.
2. Задача 2: 15 отклонений, S = 1,751 мкм, по Граббсу выбросов нет (G₁ = 2,246 < 2,549),
   ε = 2,145·0,4522 → 1 мкм, НСП Θ = 0,4 + 0,3 = 0,7 мкм (две составляющие, складываются
   арифметически), K = 1,985, Δ = 1,204 → 1,3 мкм.
3. Задача 3: g = 4π²l/T², T = 1,32 с. Погрешности аргументов даны как предельные, поэтому
   δg = δl + 2δT = 2,665·10⁻⁵, Δg = 2,7·10⁻⁴ м/с².

Все округления погрешностей — вверх, до одной значащей цифры (если первая цифра 3…9) или до
двух (если 1 или 2), как требует УМП.

## Проверочный расчёт

[main.py](main.py) повторяет ручной расчёт и печатает промежуточные значения, по нему
сверены все числа в отчёте. Вывод программы:

```text
Задача 1. Прямое однократное измерение сопротивления R
  среднее R = 7.3600 Ом
  Θ1 = Δси = 0.020 Ом, Θ2 = |Δмет| = 0.030 Ом
  Θ(0,95) = 1.10·√ΣΘi² = 0.03966 Ом -> Δ = 0.04 Ом
  Ответ: R = (7.36 ± 0.04) Ом, P = 0,95; 7.32 Ом <= R <= 7.40 Ом

Задача 2. Прямое многократное измерение диаметра d
  n = 15, Σx = 1, среднее = 0.0667 мкм
  Σ(x - x̄)² = 42.9333, S = 1.7512 мкм
  G1 = 2.246, G2 = 1.751, Gт = 2.549 -> выбросов нет
  S(x̄) = 0.4522 мкм, ε = 2.145·0.4522 = 0.9699 -> 1.0 мкм
  Θ1 = 0.40, Θ2 = 0.30 мкм, ΘΣ = Σ|Θi| = 0.70 мкм
  SΘ = 0.4041, SΣ = 0.6064 мкм, K = 1.985
  Δ = K·SΣ = 1.2040 -> 1.3 мкм
  Ответ: d = (100.0001 ± 0.0013) мм, P = 0,95; 99.9988 мм <= d <= 100.0014 мм

Задача 3. Косвенное измерение g по периоду маятника
  T = 1.32 с, ΔT = 1e-05 с, g = 4π²l/T² = 9.856010 м/с²
  δl = 1.1494e-05, δT = 7.5758e-06
  δg = δl + 2δT = 2.6646e-05, Δg = 2.6262e-04 -> 0.00027 м/с²
  Ответ: g = (9.85601 ± 0.00027) м/с²; 9.85574 <= g <= 9.85628 м/с²
  (при P < 1: δg = √(δl² + (2δT)²) = 1.9018e-05, Δg = 1.8744e-04 -> 0.00019 м/с²)
```

## Как запустить

Нужны `python3`, `pandoc` и `typst` — всё уже есть в `flake.nix` в корне репозитория.

```bash
cd ~/repos/uni
direnv allow                 # один раз
cd metrology-and-standardization/dz-1
python3 main.py              # проверочный расчёт
make                         # собрать report.pdf из report.md
```

Без direnv: `nix develop -c python3 main.py` и `nix develop -c make` из папки ДЗ.
