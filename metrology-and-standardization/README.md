# Основы метрологии и стандартизации (ОМиС)

Осенний семестр 2025/26, группа ПИН-41. В методичке и лекциях курс называется
«Метрология, стандартизация и сертификация» (МСиС). Вариант везде **1**.

Методичка по всем домашним заданиям: [УМП_ОМиС_2025.pdf](УМП_ОМиС_2025.pdf)
(учебно-методическое пособие МИЭТ, исправленное в 2025 году): теория, порядок решения,
справочные таблицы и разобранные примеры.

| Папка | Задание | Статус |
| --- | --- | --- |
| [`dz-1`](./dz-1) | ДЗ-1. Обработка результатов измерений (однократные, многократные, косвенные) | решено |
| [`dz-2`](./dz-2) | ДЗ-2. Анализ точных сопряжений (допуски и посадки) | только задание |
| [`dz-3`](./dz-3) | ДЗ-3. Расчёт размерных цепей (механизм толкателя) | только задание |
| [`dz-4`](./dz-4) | Приложение 4: Д.З.-3.1 (размерные цепи для сопряжений) и Д.З.-3.2 (параметрические цепи) | только задание |

Нумерация у преподавателя путаная: в архиве файл называется «ДЗ-4», а внутри написано
«Домашнее задание №3 (Д.З.-3.1, 3.2)». Папки названы по именам файлов из архива.
