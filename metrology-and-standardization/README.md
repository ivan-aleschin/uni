# Основы метрологии и стандартизации (ОМиС)

Осенний семестр 2025/26, группа ПИН-41. В методичке и лекциях курс называется
«Метрология, стандартизация и сертификация» (МСиС). Вариант везде **1**
(в ДЗ-2 и ДЗ-3.1 это строка 1-А, в ДЗ-3.2 — 1-1).

Методичка по всем домашним заданиям: [УМП_ОМиС_2025.pdf](УМП_ОМиС_2025.pdf)
(учебно-методическое пособие МИЭТ, исправленное в 2025 году): теория, порядок решения,
справочные таблицы и разобранные примеры.

В журнале три домашних задания (ДЗ.1 — 16 баллов, ДЗ.2 — 20, ДЗ.3 — 15). Все решены:

| Папка | Задание | Что сдавать |
| --- | --- | --- |
| [`dz-1`](./dz-1) | ДЗ-1. Обработка результатов измерений (однократные, многократные, косвенные) | `dz-1/report.pdf` |
| [`dz-2`](./dz-2) | ДЗ-2. Анализ точных сопряжений, вариант 1-А | `dz-2/report.pdf` |
| [`dz-3`](./dz-3) | ДЗ-3 (Приложение 4): Д.З.-3.1 — размерная цепь сопряжения d₄, Д.З.-3.2 — параметрическая цепь резисторов | `dz-3/report.pdf` |
| [`dz-3/tolkatel`](./dz-3/tolkatel) | Приложение 3: размерная цепь механизма толкателя + контрольные вопросы | `dz-3/tolkatel/report.pdf` |

Под ДЗ-3 в архиве подходят два файла: «ДЗ-4» (Приложение 4, внутри подписано «Домашнее
задание №3») и «ДЗ-3» (Приложение 3, толкатель, без номера). Основным считаю Приложение 4,
толкатель решён на случай, если попросят его.

В каждой папке: задание (PDF), `report.md` → `report.pdf` (чистовик для сдачи, `make`),
`main.py` (проверочный расчёт, для ДЗ-2 и ДЗ-3 ещё и рисует схемы в `fig/`),
`README.md` и `SUMMARY.md` (шпаргалка к защите).

Оформление PDF общее — шаблон [`report.typst`](./report.typst): A4, 12pt, поля 2 см,
название и подзаголовок по центру, «Дисциплина», «Выполнил», «Вариант» — отдельными
строками. Эти поля задаются в YAML-шапке `report.md` (`discipline`, `author`, `variant`).
