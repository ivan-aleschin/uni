d₁ = ∅3,6h6; d₂ = ∅4js8; d₃ = ∅4 L5-js5; d₄ = ∅4,5 E9-m5; d₅ = ∅4,5 H6-m5;
L = 46, l₁ = 6, l₂ = 22, l₃ = 38 мм. Все диаметры в интервале св. 3 до 6 мм.

Ещё в отчёте: точные размеры вала ∅3,6h6 (0/−8) и ∅4js8 (±9), допуск круглости цапф
под подшипники 0,6 мкм (Td/8 для класса 5), шероховатость всех поверхностей, свободные
размеры по 12-му квалитету, эскиз узла и эскиз вала в масштабе 3:1, схемы полей допусков
в одном масштабе (1 мкм = 1 мм).

## Проверочный расчёт и картинки

[main.py](main.py) считает все посадки и рисует картинки в `fig/` (SVG, без сторонних
библиотек): `unit.svg` — эскиз узла, `shaft.svg` — эскиз вала, `fields_*.svg` — схемы полей.
Числа в выводе совпадают с отчётом.

## Как запустить

Нужны `python3`, `pandoc` и `typst` из `flake.nix` в корне репозитория.

```bash
cd ~/repos/uni
direnv allow                 # один раз
cd metrology-and-standardization/dz-2
python3 main.py              # расчёт + картинки в fig/
make                         # report.pdf
```

Без direnv: `nix develop -c python3 main.py` и `nix develop -c make`.
