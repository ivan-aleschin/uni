# Исходные данные

Сопряжения цилиндрических поверхностей узла заданы обозначениями:
d₁ = ∅3,6h6; d₂ = ∅4js8; d₃ = ∅4 L5-js5; d₄ = ∅4,5 E9-m5; d₅ = ∅4,5 H6-m5.
Осевые размеры вала: L = 46, l₁ = 6, l₂ = 22, l₃ = 38. Все размеры в миллиметрах.

На валу установлены два шариковых подшипника качения класса точности 5 (посадка d₃),
распорная втулка (посадка d₄) и зубчатое колесо (посадка d₅). Левый подшипник
упирается в торец ступени ∅4,5 и в распорную втулку, правый — в правый торец ступени ∅4,5. Поверхности d₁ (хвостовик)
 и d₂ — точные размеры вала без сопряжения в данном узле. Для подшипника
с d = 4 мм по табл. 2.7 УМП наружный диаметр D = 13 мм, ширина B = 5 мм.

Для несопрягаемых (свободных) размеров принят 12-й квалитет и значение параметра
шероховатости Ra = 5 мкм.

Все расчёты по анализу сопряжений ведутся в микрометрах. Значения допусков и основных
отклонений взяты по ГОСТ 25346-2013 (табл. 2.3–2.5 УМП), для подшипников — по табл. 2.7 УМП.
Все номинальные размеры относятся к интервалу св. 3 до 6 мм: IT5 = 5 мкм, IT6 = 8 мкм,
IT8 = 18 мкм, IT9 = 30 мкм.

# 2. Анализ точных размеров и сопряжений

## Точные размеры вала d₁ и d₂

**d₁: ∅3,6h6.** Основное отклонение h: es = 0, допуск IT6 = 8 мкм, ei = −8 мкм;\
∅3,6h6$(_{\text{−0,008}})$; Td = es − ei = 0 − (−8) = 8 мкм.

Шероховатость: Rz ≤ 0,3·Td = 0,3·8 = 2,4 мкм; предпочтительные значения Rz = 1,6 мкм, Ra = 0,32 мкм.

**d₂: ∅4js8.** Поле симметричное: es = +IT8/2 = +9 мкм, ei = −9 мкм; ∅4js8(±0,009);\
Td = 9 − (−9) = 18 мкм.

Шероховатость: Rz ≤ 0,3·18 = 5,4 мкм; предпочтительные значения Rz = 3,2 мкм, Ra = 0,63 мкм.

## Посадка d₃: ∅4 L5-js5

Отверстие (внутреннее кольцо подшипника класса 5, табл. 2.7): ES = 0, EI = −5 мкм;\
∅4 L5$(_{\text{−0,005}})$; T~D~ = ES − EI = 0 − (−5) = 5 мкм.

Вал: es = +2,5 мкм, ei = −2,5 мкм; ∅4js5(±0,0025); T~d~ = es − ei = 2,5 − (−2,5) = 5 мкм.

Сопряжение:

S~max~ = ES − ei = 0 − (−2,5) = +2,5 мкм;\
S~min~ = EI − es = −5 − 2,5 = −7,5 мкм;\
S~m~ = 0,5(S~max~ + S~min~) = 0,5(2,5 − 7,5) = −2,5 мкм;\
T~S~ = S~max~ − S~min~ = 2,5 − (−7,5) = 10 мкм.

Проверка: T~S~ = T~D~ + T~d~ = 5 + 5 = 10 мкм.

T~S~^P^ = √(T~D~² + T~d~²) = √(5² + 5²) = 7,071 мкм; 0,5·T~S~^P^ = 3,536 ≈ 3,5 мкм;

S^P^~max~ = S~m~ + 0,5·T~S~^P^ = −2,5 + 3,5 = +1,0 мкм;\
S^P^~min~ = S~m~ − 0,5·T~S~^P^ = −2,5 − 3,5 = −6,0 мкм.

![Схема расположения полей допусков сопряжения ∅4 L5-js5](fig/fields_d3.svg){width=55%}

Характеристика посадки: подшипниковая посадка в системе отверстия, переходная.

Вероятности образования зазоров и натягов (табл. 2.9):

z = 6·|S~m~| / T~S~^P^ = 6·2,5 / 7,071 = 2,121 ≈ 2,12; Ф(z) = 0,48300;\
P~N~ = 0,5 + Ф(z) = 0,98300; P~S~ = 0,5 − Ф(z) = 0,01700.

Допуск круглости цапфы вала (сопряжение с подшипником класса 5):
T₀ ≤ T~d~ / 8 = 5 / 8 = 0,625 мкм; предпочтительное значение T₀ = 0,6 мкм.

Шероховатость цапфы вала: Rz ≤ 0,3·T~d~ = 0,3·5 = 1,5 мкм; Rz ≤ 0,4·T₀ = 0,4·0,6 = 0,24 мкм;\
предпочтительные значения Rz = 0,2 мкм, Ra = 0,04 мкм.

## Посадка d₄: ∅4,5 E9-m5

Отверстие (распорная втулка): основное отклонение E: EI = +20 мкм, IT9 = 30 мкм,
ES = EI + IT9 = +50 мкм; ∅4,5E9$(^{\text{+0,050}}_{\text{+0,020}})$; T~D~ = 50 − 20 = 30 мкм.

Вал: основное отклонение m: ei = +4 мкм, IT5 = 5 мкм, es = +9 мкм;\
∅4,5m5$(^{\text{+0,009}}_{\text{+0,004}})$; T~d~ = 9 − 4 = 5 мкм.

Сопряжение:

S~max~ = ES − ei = 50 − 4 = +46 мкм;\
S~min~ = EI − es = 20 − 9 = +11 мкм;\
S~m~ = 0,5(46 + 11) = +28,5 мкм;\
T~S~ = 46 − 11 = 35 мкм.

Проверка: T~S~ = T~D~ + T~d~ = 30 + 5 = 35 мкм.

T~S~^P^ = √(30² + 5²) = 30,414 мкм; 0,5·T~S~^P^ = 15,207 ≈ 15,2 мкм;

S^P^~max~ = 28,5 + 15,2 = +43,7 мкм;\
S^P^~min~ = 28,5 − 15,2 = +13,3 мкм.

![Схема расположения полей допусков сопряжения ∅4,5 E9-m5](fig/fields_d4.svg){width=55%}

Характеристика посадки: посадка внесистемная (комбинированная) с зазором.

Шероховатость поверхностей:
отверстия втулки Rz ≤ 0,3·30 = 9 мкм, предпочтительные значения Rz = 6,3 мкм, Ra = 1,25 мкм;\
вала Rz ≤ 0,3·5 = 1,5 мкм, предпочтительные значения Rz = 0,8 мкм, Ra = 0,16 мкм.

## Посадка d₅: ∅4,5 H6-m5

Отверстие (ступица зубчатого колеса): EI = 0, ES = +IT6 = +8 мкм; ∅4,5H6$(^{\text{+0,008}})$;\
T~D~ = 8 мкм.

Вал: es = +9 мкм, ei = +4 мкм; ∅4,5m5$(^{\text{+0,009}}_{\text{+0,004}})$; T~d~ = 5 мкм.

Сопряжение:

S~max~ = ES − ei = 8 − 4 = +4 мкм;\
S~min~ = EI − es = 0 − 9 = −9 мкм;\
S~m~ = 0,5(4 − 9) = −2,5 мкм;\
T~S~ = 4 − (−9) = 13 мкм.

Проверка: T~S~ = T~D~ + T~d~ = 8 + 5 = 13 мкм.

T~S~^P^ = √(8² + 5²) = 9,434 мкм; 0,5·T~S~^P^ = 4,717 ≈ 4,7 мкм;

S^P^~max~ = −2,5 + 4,7 = +2,2 мкм;\
S^P^~min~ = −2,5 − 4,7 = −7,2 мкм.

![Схема расположения полей допусков сопряжения ∅4,5 H6-m5](fig/fields_d5.svg){width=55%}

Характеристика посадки: посадка в системе отверстия переходная.

Вероятности образования зазоров и натягов (табл. 2.9):

z = 6·|S~m~| / T~S~^P^ = 6·2,5 / 9,434 = 1,590 ≈ 1,59; Ф(z) = 0,44408;\
P~N~ = 0,5 + Ф(z) = 0,94408; P~S~ = 0,5 − Ф(z) = 0,05592.

Шероховатость поверхностей:
отверстия зубчатого колеса Rz ≤ 0,3·8 = 2,4 мкм, предпочтительные значения Rz = 1,6 мкм,
Ra = 0,32 мкм; вала — та же поверхность ∅4,5m5, что и в посадке d₄: Rz = 0,8 мкм, Ra = 0,16 мкм.

Все схемы полей допусков выполнены в одном масштабе.
