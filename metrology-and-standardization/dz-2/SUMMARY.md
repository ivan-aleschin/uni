# ДЗ-2 на пальцах: анализ точных сопряжений

## Суть

Посадка — это пара «отверстие + вал» с одним номинальным диаметром. У каждого из них
есть поле допуска: квалитет задаёт ширину поля (IT), буква — где поле стоит относительно
нуля (основное отклонение). По полям считаем, какие зазоры или натяги получатся в худшем
случае (Smax, Smin) и в реальном, вероятностном (поле зазоров уже, потому что допуски
складываются квадратично). Дальше определяем систему посадки и её характер, для
подшипника ограничиваем форму цапфы и назначаем шероховатость каждой поверхности.

## Что считаем

| Шаг | Как | Пример (d₄ = ∅4,5 E9-m5) |
| --- | --- | --- |
| отклонения | ГОСТ 25346 / табл. 2.3–2.5: E → EI = +20, IT9 = 30; m → ei = +4, IT5 = 5 | ES/EI = +50/+20, es/ei = +9/+4 |
| предельные зазоры | Smax = ES − ei, Smin = EI − es | +46 / +11 |
| вероятностные | T_S^P = √(TD² + Td²), S^P = Sm ± 0,5·T_S^P | Sm = 28,5, ±15,2 → +43,7 / +13,3 |
| переходная посадка | z = 6·|Sm|/T_S^P, Ф(z) по табл. 2.9 | d₅: z = 1,59, P_N = 0,944 |
| форма | подшипник класса 5: T₀ ≤ Td/8 | d₃: 5/8 → 0,6 мкм |
| шероховатость | Rz ≤ 0,3·T и Rz ≤ 0,4·T₀, берём ближайшее меньшее Rz, по нему Ra | цапфа: Rz 0,2 → Ra 0,04 |

## Вывод и откуда он

- **d₃ ∅4 L5-js5** — переходная, но почти всегда с натягом (P_N = 98,3 %): поле L5
  внутреннего кольца лежит ниже нуля, а js5 вала симметрично относительно нуля. Внутреннее
  кольцо подшипника считается основным отверстием, поэтому посадка в системе отверстия.
- **d₄ ∅4,5 E9-m5** — гарантированный зазор 11…46 мкм: E9 целиком выше m5. Ни одно поле
  не основное (не H и не h), поэтому посадка внесистемная. Втулка свободно надевается
  на вал.
- **d₅ ∅4,5 H6-m5** — переходная в системе отверстия, натяг в 94,4 % случаев, это
  нормально для колеса на шпонке.
- Самый жёсткий параметр — цапфы под подшипники: круглость 0,6 мкм и Ra 0,04, потому что
  класс подшипника 5 требует T₀ ≤ Td/8.

## Как рассказывать

> По таблицам ГОСТ 25346 для диаметров от 3 до 6 мм нашёл отклонения отверстий и валов,
> для подшипника — по таблице 2.7 УМП. Для каждой посадки посчитал предельные зазоры:
> максимальный — разность верхнего отклонения отверстия и нижнего вала, минимальный —
> наоборот. Вероятностные границы уже, так как допуски складываются квадратично.
> Посадка d₃ — подшипниковая переходная, d₄ — внесистемная с зазором, d₅ — переходная
> в системе отверстия. Для переходных посадок через функцию Лапласа нашёл вероятность
> натяга, на цапфы под подшипники класса 5 назначил круглость Td/8 = 0,6 мкм, а для всех
> поверхностей — шероховатость через Rz ≤ 0,3T.

## Возможные вопросы

1. **Чем посадка в системе отверстия отличается от системы вала?** В системе отверстия
   отверстие основное (H, EI = 0), а разные посадки получают, меняя поле вала; в системе
   вала наоборот, основной вал h (es = 0).
2. **Почему E9-m5 внесистемная?** Ни E, ни m не основные отклонения, посадка составлена
   из двух произвольных полей.
3. **Почему посадка подшипника в системе отверстия, хотя поле L5 не H?** Внутреннее кольцо
   стандартного подшипника — это готовое основное отверстие, по нему подбирают вал. Поле L
   лежит ниже нуля (ES = 0), это особенность подшипников.
4. **Откуда вероятностные границы?** При нормальном законе и P = 0,9973 рассеяние зазора
   равно √(TD² + Td²), центр — средний зазор Sm.
5. **Как считается вероятность натяга?** z = 6|Sm|/T_S^P, Ф(z) по таблице; если Sm < 0,
   то P_N = 0,5 + Ф(z). Для d₃: z = 2,12, Ф = 0,483, P_N = 0,983.
6. **Почему круглость 0,6, а не 0,625?** Расчётное значение округляется до ближайшего
   меньшего предпочтительного из табл. 2.8.
7. **Почему у цапфы Ra = 0,04, а не 0,16?** Из двух условий (по допуску размера и по
   допуску формы) берётся более жёсткое: 0,4·0,6 = 0,24 → Rz 0,2 → Ra 0,04.
8. **Как записаны свободные размеры?** По 12-му квалитету: длина вала 46₋₀,₂₅ как
   размер вала (h12), остальные осевые ±IT12/2.
