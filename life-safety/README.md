# Безопасность жизнедеятельности (БЖД)

| Работа | Тема |
| --- | --- |
| [`lab-1`](./lab-1) | Исследование параметров микроклимата |
| [`lab-5`](./lab-5) | Исследование средств защиты от тепловых излучений |

В каждой папке лабы три файла:

| Файл | Что это |
| --- | --- |
| `задание.docx` | методичка, пережатая без потерь |
| `README.md` | конспект на один лист — переписать в тетрадь перед лабой |
| `SUMMARY.md` | шпаргалка, чтобы быстро вникнуть и ответить на вопросы |

## Как сжимались методички

Методички пришли в `.docx`: формулы там — мелкие векторные WMF, рисунки — PNG. Перевод в PDF
места не экономит, поэтому оставлен `.docx`: PNG пережаты `oxipng` (без потерь), архив
пересобран с максимальным сжатием.

```bash
direnv allow                       # в корне репо, один раз (oxipng и zip — из flake.nix)
./compress-docx.sh исходник.docx lab-N/задание.docx
# запасной вариант: nix develop -c ./compress-docx.sh …
```
