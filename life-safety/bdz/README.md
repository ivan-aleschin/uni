## Результаты варианта 1

| Задание | Исходные данные | Результат |
| --- | --- | --- |
| 1. Тяжесть и напряжённость труда | инженер-разработчик, 9 факторов (табл. 1.3) | ΣX_ф = 16,625, X_max = 3, U_T = 3,85 → **3-я категория** |
| 2. Качество воды | Al 0,4; Be 0,0001; бутилен 0,15; ацетон 2,0; хлор активный 0,0001 мг/л | Al/ПДК + Be/ПДК = 0,8 + 0,5 = **1,3 > 1**, хлор при норме «отсутствие» → вода **не питьевая** |
| 3. ЧС и первая помощь | 17 рекомендаций × 9 природных опасностей; вариант 1 — солнечный удар | таблица «+» с пояснениями; последовательность ОПП по приказу Минздрава № 220н |

Что стоит знать о решениях, которые можно оспорить:

- **Непрерывная работа 8 ч** взята за 3 балла: в шкале «2 балла» — «< 8 ч», а 8 не меньше 8.
  При 2 баллах U_T = 3,54, категория та же.
- **N = 9**: освещённость (размер объекта и разряд работы) — один фактор, как в примере методики,
  где 12 оценок относятся к N = 11. При N = 10 U_T = 3,76, категория та же.
- **Льготы** по категории задаются в Приложении 1, которого в выданной методичке нет. В отчёте
  описан принцип (надбавка, доп. отпуск, сокращённый день) и ориентир из примера: 5-я категория —
  16 % и 7 дней. Если Приложение 1 найдётся, точные цифры для 3-й категории дописать в п. 1.4.
- **Хлор активный**: в табл. 2.1 вместо ПДК — «отсутствие». Понимаю это как запрет на его
  присутствие, поэтому 0,0001 мг/л — нарушение (в примере методики хлор записан как «ПДК не
  установлена», но вывод от этого не меняется: сумма 1,3 > 1 уже даёт «не питьевая»).
- **Первая помощь** составлена по действующему Порядку (приказ № 220н, с 01.09.2024) и практикуму
  Мищенко; нашатырный спирт из практикума сознательно не включён — его нет в Порядке.

Теория для задания 3 бралась из трёх пособий, которые не лежат в репозитории (Мищенко,
«Безопасность жизнедеятельности: практикум», 2013; Сычев, «БЖД в чрезвычайных ситуациях», 2005;
лекция «ЧС природного характера»), — ссылки на страницы в отчёте.

## Как запустить

Нужны `python3` и `pandoc` из `flake.nix` в корне репозитория.

```bash
cd ~/repos/uni
direnv allow                 # один раз
cd life-safety/bdz
python3 main.py              # проверочный расчёт, числа совпадают с отчётом
make                         # report.md -> report.docx
```

Без direnv: `nix develop -c python3 main.py` и `nix develop -c make`.
