## Часть 1. Исследование естественного освещения

**Цель:** изучить влияние освещённости на работоспособность человека, ознакомиться
со светотехническими характеристиками, экспериментально определить параметры
естественного освещения в лаборатории.

**Задачи:** 1) ознакомиться с характеристиками освещённости, их влиянием на человека
и приборами; 2) определить параметры естественного освещения и их соответствие нормам;
3) разработать рекомендации по нормализации.

**Приборы:** люксметр Ю116, лабораторные планшеты.

**КЕО** — отношение освещённости в точке помещения к наружной освещённости от всего
небосвода: e = E_в / E_н · 100 %. Виды: боковое (одно-, двухстороннее), верхнее, комбинированное.

| Формула | Смысл |
| --- | --- |
| e_N = e_н · m_N, m_N = 0,9 | нормированный КЕО (1) |
| S_о = S_п · e_N · η_о · K_з · K_зд / (100 · τ_о · r₁) | площадь окон (2) |
| τ_о = τ₁ · τ₂ · τ₃;  n = S_о / S₁ | светопропускание, число окон |
| e_рн = 0,01 · n₁ · n₂ | метод Данилюка (3) |
| e = e_н + e_о + e_зд;  e_н = e_рн · τ_о · q;  e_о = e_н · (r − 1), r = 1,65;  e_зд = 0,1 · e_рн · τ_о | фактический КЕО (4–7) |

## Часть 2. Исследование искусственного освещения

**Цель:** ознакомиться со светотехническими характеристиками, экспериментально определить
параметры искусственного освещения в лаборатории.

**Задачи:** 1) ознакомиться с характеристиками освещённости и приборами; 2) определить
параметры искусственного освещения и их соответствие нормам; 3) разработать рекомендации.

**Приборы:** стенд — макет помещения, люксметр-пульсаметр.

**Классификация:** по организации — общее (равномерное, локализованное), комбинированное
(общее + местное; только местное запрещено); по назначению — рабочее, аварийное (≥ 5 %
нормы, ≥ 2 лк), эвакуационное (≥ 0,5 лк), охранное (≥ 0,5 лк), дежурное.

**Источники:** накаливания (8–10 лм/Вт, < 2000 ч), галогенные (15–22 лм/Вт, 4000 ч),
люминесцентные (30–105 лм/Вт, > 10 000 ч), ДРЛ (70–150 лм/Вт), светодиоды (> 150 лм/Вт, 35–70 тыс. ч).
Нормы — СНиП 23-05-95.
