## Общие сведения

- **Трёхпроводная** сеть — фазы A, B, C; **четырёхпроводная** — A, B, C + нулевой N (PEN).
- Режимы нейтрали (ПУЭ, до 1000 В): **изолированная** (трёхпроводная) и **глухозаземлённая** (четырёхпроводная).
- U_л = √3 · U_ф = 1,73 · 220 = 380 В.
- **Однофазное** прикосновение — фаза–земля (чаще, напряжение ≤ U_ф);
  **двухфазное** — две фазы (самое опасное, U_л, от нейтрали не зависит).

## Часть 2. Оценка эффективности защитного заземления

**Цель:** анализ эффективности защитного заземления в электроустановках, питающихся от
трёхпроводных сетей с изолированной нейтралью и четырёхпроводных с заземлённой нейтралью.

**Задачи:** 1) ознакомиться с принципом действия защитного заземления; 2) оценить его
эффективность в сети с изолированной нейтралью; 3) — в сети с заземлённой нейтралью.

**Защитное заземление** — преднамеренное соединение с землёй нетоковедущих металлических
частей (корпусов) через заземлитель и заземляющий проводник. Снижает напряжение прикосновения.

| Случай | Формула |
| --- | --- |
| Без заземления, изол. (1) | I_ч = U_ф / (R_ч + R_п + R_об + R/3) |
| С заземлением, изол. (2) | I_ч = 3·U_ф·R_з / (R_ч·R) |
| Напряжение на корпусе (3), ток (4) | U_з = 3·U_ф·R_з / R;  I_з = U_з / R_з |
| С заземлением, заземл. нейтраль (5) | I_ч = U_ф·R_з / (R_ч·(R₀ + R_з)) |

Пример (5): R₀ = 1,5 Ом, R_з = 4 Ом → на корпусе 160 В, I_ч = 0,16 А — **смертельно**.
